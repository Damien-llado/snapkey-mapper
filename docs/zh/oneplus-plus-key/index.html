OnePlus 允许 Plus Key 做什么

在多款 OnePlus 机型上，Plus Key 取代了提示滑块的位置。你在手机设置里为它选一项功能。r/oneplus 上的用户提到他们用的选项有：Mind Space（OnePlus 的 AI）、手电筒、相机、截屏、录音机、翻译、勿扰模式，以及响铃、振动、静音切换。具体列表取决于机型和软件版本。

设置里没有的，恰恰是你真正想要的应用。用户一直在要：自己的助手、第三方相机应用，或者双击、三击时执行不同的操作。

应用补上了什么

一个 Plus Key，四个快捷方式

每种手势各自打开自己的目标。设一个、两个、三个或全部四个都行。

  • 四种手势

    单击、双击、三击和长按（半秒）。只有设置了更长的连按，较短的连按才会等一小会儿（不到一秒）来区分它们；否则立即触发。

  • 任意应用或链接

    选一个已安装的应用，粘贴一个链接，或者写一条 intent: 链接，调用 Android 能做的任何事。按键就能打开它，无需 root。

  • 内置操作

    手电筒开关、响铃再振动再静音、播放或暂停、下一首和上一首。不会打开任何应用：操作直接执行。静音需要勿扰权限，只需允许一次。

  • 录音机

    一个快捷方式就能打开手机的录音机，随时可以录语音笔记。

  • 快捷方式库

    按应用分组的现成快捷方式，每项内容一个字段，还有测试按钮。查看快捷方式库。

设置

在 OnePlus 上设置

简要版。完整指南里有每个界面，以及各种错误的解决办法。

  1. 让按键不再执行自带功能

    在手机设置中打开 Plus Key 的设置。如果有“不执行任何操作”之类的选项，就选它，这样按键就不会同时打开 Mind Space 或手电筒。在 OPPO 手机上，系统仍会记录每次按键，所以 SnapKey Mapper 照常工作；如果你的 OnePlus 表现不同，请在 GitHub 上告诉我们。

  2. 安装 APK 并允许受限制的设置

    下载 APK 并打开。然后进入 设置 › 应用 › SnapKey Mapper，点 ⋮，再点允许受限制的设置：对于 Play 商店以外安装的任何应用，Android 都会要求这一步。

  3. 让应用自己获取日志权限

    应用需要一个权限 READ_LOGS，Android 允许你无需 root 授予一次。完整版通过手机自带的无线调试来完成：只需这一次连上 Wi-Fi，不需要电脑。OxygenOS 上的界面可能有所不同，有些版本需要先打开一个隐藏开关：完整指南的第 3 步有说明。

  4. 选择每种手势打开什么

    为单击、双击、三击和长按分别选一个应用、一个链接或一个内置操作，然后点测试。之后应用会自动监听。

常见问题

关于 Plus Key 的问题

能把 OnePlus Plus Key 改成打开任意应用吗？

只靠 OnePlus 的设置不行：它只提供固定的几个功能。用 SnapKey Mapper 就可以：任意已安装的应用或任意链接，而且单击、双击、三击、长按可以各开不同的。

Plus Key 能设双击或三击吗？

可以。单击、双击、三击和长按各有自己的目标，可以是应用、链接或内置操作。要清空某个手势，在应用里选中它，再点移除。

能把 Plus Key 当提示滑块用吗？

可以。内置操作响铃、振动、静音每按一次就切换到下一种模式。静音需要勿扰权限，Android 会请你授予一次；没有这项权限的话，振动之后会回到响铃。和手机自带设置的区别在于：手势由你选，其余手势还能留给别的用途。

能把手电筒设在 Plus Key 上吗？

可以。内置操作打开或关闭手电筒会打开手电筒，已经开着就关闭。不会打开任何应用。

能截屏、切换勿扰模式或启动圈选即搜吗？

不能作为内置操作。内置操作有手电筒、响铃、振动和静音、播放或暂停、下一首和上一首。能从应用或链接打开的内容也可以，但截屏或勿扰开关不行。

需要 root、Shizuku 或 Tasker 吗？

不需要。应用只需要一个权限 READ_LOGS，它通过手机的无线调试自行授予一次。无需 root，无需 Shizuku，无需 Tasker，也无需无障碍服务。首页的常见问题解释了应用能看到什么、不能看到什么。

哪些 OnePlus 手机有 Plus Key？

应用支持 OnePlus 15、15R、13s、13T 和 Nord 5 的 Plus Key。13s 和 13T 配有这个按键。如果你的手机有 Plus Key 但没列出来，请试一试，并在 GitHub 上告诉我们。

我的 OnePlus 上不能用，怎么办？

在应用里打开在我的手机上不起作用？：它会重新启动监听，如果按键特征被改过就恢复原始特征，并准备好一份 GitHub issue，附上你的机型、系统和版本。你也可以从应用的“找到你的按键”功能里，把你的按键对应的日志行发给我们。
