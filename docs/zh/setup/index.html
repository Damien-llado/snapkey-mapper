开始之前

你需要准备

  • 一部带 Snap Key 的 OPPO 手机，或带 Plus Key 的 OnePlus 手机，系统为 Android 11 或更高版本。
  • Wi-Fi，只需一次，用于授权这一步。之后应用用移动数据或关掉 Wi-Fi 都能用。
  • APK，从 GitHub Releases 下载。完整版可以直接在手机上给自己授权；精简版没有联网权限，需要在电脑上运行一次 adb 命令。

安装过程中，Android 和 Google Play Protect 可能会弹出一些警告，因为这个应用不在 Google Play 上。Android 会提示什么里有解释，还附有用来核对的签名指纹。

步骤

6 步完成设置

简要版。每一步都链接到首页上的完整说明。

  1. 把 OPPO 自带的 Snap Key 功能设为无

    在 设置 › Snap Key 中，把按键设为不执行任何操作，这样它就不会再触发 AI Mind Space 或手电筒。ColorOS 仍会记录每次按键，SnapKey Mapper 照常工作。

  2. 安装 APK 并允许受限制的设置

    下载 APK 并打开。然后进入 设置 › 应用 › SnapKey Mapper，点 ⋮，再点允许受限制的设置：对于 Play 商店以外安装的任何应用，Android 都会要求这一步。

  3. 让应用自己获取日志权限

    应用需要一个权限 READ_LOGS。在 ColorOS 上要先打开一个隐藏开关，而且它只在手机语言为英语时才会显示：把手机切换为英语，在设置里搜索 Disable system optimisation 并开启，然后把语言改回来。连上你的 Wi-Fi，在应用里点打开无线调试，用通知里的配对码配对，通知提示设置完成后就关闭无线调试。这一步的每个界面都在首页上。

  4. 允许显示在其他应用的上层，并放开电池限制

    在 SnapKey Mapper 中，点允许显示在其他应用的上层和电池不受限制。在 ColorOS 上，还要把应用的耗电设置为无限制，并在最近任务中锁定 SnapKey Mapper。

  5. 选择每种按法打开什么

    为单击、双击、三击和长按分别选一个已安装的应用、粘贴一个链接，或从快捷方式库选一个快捷方式，然后点测试。需要点子？看看快捷方式创意。

  6. 自动监听

    只要选好了内容，SnapKey Mapper 就会开始监听。Android 13 及以上会询问允许访问所有设备日志吗？：选择允许访问一次。只有重启后才会再看到。

出问题了怎么办

常见故障

Android 阻止安装，或提示应用有害

这是 Chrome 或 Google Play Protect 对 Play 商店以外的应用做出的反应。把 APK 的签名证书与首页上的指纹核对，然后选择仍要安装。

无法开启“显示在其他应用的上层”

在你为该应用允许受限制的设置之前，Android 可能会拒绝这项权限：应用信息 › ⋮ › 允许受限制的设置，然后返回再授予权限。

设置完成后按键没反应

在应用里打开在我的手机上不起作用？。它会重新启动监听，如果按键特征被改过就恢复原始特征，并准备好一份 GitHub issue，附上你的机型、系统和版本。应用里“找到你的按键”的功能也会显示你的按键写下的日志行。

常见问题里有更多解答。在你的手机上不能用？在 GitHub 上告诉我们。
