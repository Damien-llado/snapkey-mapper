OPPO Snap Key 快捷方式：每种按法该设什么

侧键的十二个点子，从手电筒到智能家居面板。每个点子都说明它能做什么、适合哪种按法，以及如何在 SnapKey Mapper 中设置。SnapKey Mapper 是免费应用，让按键打开任意应用、链接或内置操作。

点子

选一种用法

前四项按 OPPO 和 OnePlus 用户在按键相关 Reddit 帖子里（r/oneplus 和 r/Oppo，2026 年 11 月查阅）提到各种用法的频率排序。这个排名只是大致的：它来自统计提及次数，不是问卷调查，而且这些帖子两个品牌都有。其余的是应用已经支持的点子。

  • 手电筒
  • 响铃模式
  • 语音笔记
  • AI 助手
  • 音乐
  • 笔记
  • 相机
  • 翻译、Shazam
  • Google Wallet
  • 智能家居
  • 导航
  • 计时器

一套好用的配置：单击开手电筒，双击打开你的 AI 助手（放在口袋里误按一下永远不会打开它），三击录语音笔记，长按播放或暂停。只有设置了更长的连按，按键才会在按下后等一小会儿（不到一秒）来区分它们。

手电筒

打开手电筒，已经开着就关闭。不会打开任何应用。这是用户提到最多的用法，尽管设置里本来就有手电筒这个选项：他们要的是把手电筒放在一种手势上，其他手势留给别的用途。

  • 建议按法 单击
  • 设置方法 内置操作打开或关闭手电筒

响铃、振动、静音

代替提示滑块。每按一次就切换到下一种模式：响铃、振动、静音。只有在你允许勿扰权限之后，Android 才允许应用切换到静音，这一步在应用里做一次即可；没有这项权限的话，振动之后会回到响铃。

  • 建议按法 双击
  • 设置方法 内置操作响铃、振动、静音，再加快捷方式允许静音模式

语音笔记

打开手机的录音机，随时可以录语音笔记。它只是打开录音机，录音键还要你自己点。

  • 建议按法 三击
  • 设置方法 快捷方式库中的打开录音机

AI 助手

用 Claude、ChatGPT、Gemini 或 Perplexity 代替 OPPO 自带的助手。按键会打开你选的应用；对 Claude，快捷方式库还有新建对话和新建 Claude Code 会话的快捷方式。库里没有直接进入助手语音模式的快捷方式：按键打开的是应用。

  • 建议按法 双击
  • 设置方法 选择已安装的应用，或者对 Claude 用快捷方式库中的新对话，对手机的默认助手用打开语音助手

音乐

不用打开音乐应用，就能播放或暂停当前内容，跳到下一首或上一首。按键发出的指令和耳机按键一样，所以 Spotify、YouTube Music 或播客应用都会响应。你也可以打开播放列表或专辑：快捷方式库里有 Spotify、YouTube Music、Deezer 和 Apple Music 的快捷方式。

  • 建议按法 长按播放或暂停，三击切到下一首
  • 设置方法 内置操作播放或暂停、下一首、上一首

快速笔记

一按就打开你的笔记应用。快捷方式库里有 Obsidian（新建笔记、今天的日记、在日记里加一行）、Notion、Google Docs 和 Todoist 的快捷方式。Google Keep 的话，选这个应用即可：按键会打开它，但不会开始一条新笔记。

  • 建议按法 三击
  • 设置方法 快捷方式库中 Obsidian、Notion、Google Docs 或 Todoist 的快捷方式，或选择已安装的应用

相机

一按就打开相机，相当于手机侧面的快门键。快捷方式库可以用拍照模式或录像模式打开默认相机，你也可以选别的相机应用。

  • 建议按法 单击
  • 设置方法 快捷方式库中的以拍照模式打开相机或以录像模式打开相机

翻译和听歌识曲

用户想把 Google 翻译和 Shazam 放到按键上。按键只是打开应用，不会替你开始翻译或搜索歌曲，所以进入应用后你还要再点一下。

  • 建议按法 长按
  • 设置方法 选择已安装的应用（暂时没有对应的快捷方式）

Google Wallet

用户还想要钱包，用来放银行卡或车钥匙。按键会打开 Google Wallet 应用，但不会替你付款。

  • 建议按法 双击
  • 设置方法 选择已安装的应用（暂时没有对应的快捷方式）

智能家居

直接用按键打开 Home Assistant 的某个仪表盘页面，比如灯光或车库门那一页。要触发工作流，快捷方式库里还有一个调用 n8n Webhook 的快捷方式：它是以链接的方式工作的，所以会在浏览器里打开，而不是在后台静默运行。

  • 建议按法 三击
  • 设置方法 快捷方式库中的打开仪表盘页面（Home Assistant）或运行工作流（Webhook）（n8n）

导航

按一下就开始逐向导航，去一个保存的地点，比如家或健身房。Google Maps 可以开始步行、骑行或驾车导航；Waze 可以导航回家或去公司。

  • 建议按法 长按
  • 设置方法 快捷方式库中 Google Maps（导航到某个地址）或 Waze（导航回家）的快捷方式

计时器和闹钟

立即开始倒计时，不用打开时钟应用：煮面五分钟，工作时段二十五分钟。快捷方式库还能设置闹钟。

  • 建议按法 长按
  • 设置方法 快捷方式库中的开始计时器，时长以秒为单位

方法

在应用里哪里找

在 SnapKey Mapper 中，选一种手势，然后选一个已安装的应用、粘贴一个链接，或打开快捷方式库。快捷方式库按应用分组现成的快捷方式，每项内容一个字段，还有测试按钮。内置操作（手电筒、响铃模式、播放或暂停、下一首和上一首）在快捷方式库的手机操作下。

内置操作从 1.0.13 版起提供，尚未在每部手机上测试过：设置好后请点测试，如果不起作用，请用应用里的在我的手机上不起作用？告诉我们。更新日志列出了每个版本新增的内容。
