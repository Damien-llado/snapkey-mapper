OPPO 手机上的 Snap Key 是什么？

Snap Key 是部分 OPPO 手机（如 Find X9 系列）机身左侧上方的一个实体按键。在 ColorOS 上，它只能从一份简短的固定列表里执行一项功能，比如 AI Mind Space 或手电筒。免费应用 SnapKey Mapper 能让它改为打开任意应用或链接。

默认情况

Snap Key 开箱即有的功能

在 ColorOS 16 上，Snap Key 只能执行 OPPO 列出的功能：AI Mind Space、相机、手电筒、录音、翻译、截屏、声音模式或勿扰模式。你在手机设置中选其中一项。没有“打开你选的应用”这个选项。

这正是 SnapKey Mapper 补上的缺口。它保留按键，并补上设置里缺少的功能。

你想要ColorOS 设置SnapKey Mapper

打开链接、深层链接或 Intent不在列表中可以
使用单击、双击、三击和长按按键只有一项功能四种手势，各有一个目标
手电筒、响铃、振动、静音在列表中内置操作，可设在任意手势上

ColorOS 一列描述的是 OPPO Find X9 Pro 在 ColorOS 16 上的设置，这是开发和使用这个应用的手机。其他机型和版本上的列表可能不同。

手机

哪些手机有 Snap Key

Snap Key 是 OPPO 新款手机的侧键。Reno 16 系列称它为 AI Snap Key。OnePlus 部分机型上有类似的按键，叫 Plus Key。SnapKey Mapper 支持下列按键。

在你的手机上不能用？请在 GitHub 上告诉我们，并附上机型和你的按键对应的日志行。

技术原理

应用怎样使用被 ColorOS 锁定的按键

每次按 Snap Key，系统日志里都会留下一行 KEYCODE_ACTION_BUTTON_CLICK。SnapKey Mapper 读取日志，发现这一行，就打开你选的应用或链接。它需要一个权限 READ_LOGS，Android 允许你无需 root 授予一次。不用无障碍服务，应用也不收集任何数据。

常见问题

关于 Snap Key 的问题

OPPO 快捷键（Snap Key）是什么？

部分 OPPO 手机机身左侧上方的实体按键。在设置里，你从固定列表中为它选一项功能。用 SnapKey Mapper，它可以打开任意应用或链接，单击、双击、三击和长按还能各开不同的内容。

Snap Key 和 OnePlus Plus Key 是同一个东西吗？

它们是同一集团手机上类似的侧键。SnapKey Mapper 两种都支持：见 OnePlus Plus Key 页面。

Reno 16 的 AI Snap Key 是什么？

这是 OPPO Reno 16、Reno 16 Pro 和 Reno 16 F 对自己侧键的叫法。应用支持它。如果你的没反应，请 在 GitHub 上告诉我们。

Snap Key 能打开任意应用吗？

只靠 OPPO 的设置不行，它只提供固定的几个功能。用 SnapKey Mapper 就可以：任意已安装的应用或任意链接。

它和其他叫 Snap Key 的产品有关系吗？

没有。这个名字也被用在不相关的东西上，比如键盘功能和游戏设置。本页只讲 OPPO 手机的侧键。
