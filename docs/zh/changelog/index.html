1.0.12 最新

2026-11-13发布页

变更

  • “在我的手机上不能用？”现在先给出常见解决办法：重新开始监听；按键特征被修改过时，还有恢复原始特征。报告问题放在最后。
  • 按键识别：点按一行不再在不提示的情况下替换可用的特征。确认框会显示当前特征和新特征。
  • 按键识别：如果该行包含按键代码（KEYCODE_…），建议的特征就是它。
  • 按键识别：特征输入框会保持显示在键盘上方。
  • 按键识别会说明 OPPO 的 Snap Key 和 OnePlus 的 Plus Key 已经内置。

1.0.11

2026-11-13发布页

新增

  • 在主屏幕和每个设置步骤底部新增"在我的手机上不起作用？"入口，有两个选择：用按键查找器自己找到按键并分享（会打开一个 GitHub issue，只附上手机型号、系统和所选的那一行，绝不包含捕获的其余内容），或交给我们修复（打开一个已填好诊断信息的 GitHub issue，发布前由你先阅读）。

变更

  • 诊断信息现在显示手机的商品名称（"OPPO Find X9 Pro"），在 OnePlus 手机上还显示 OxygenOS 版本。
  • 按键查找器会说明捕获的行可以点按，并在底部栏确认已保存的按键。

1.0.10

2026-11-12发布页

新增

  • 新增五种语言：印度尼西亚语、意大利语、日语、越南语和泰语（共 13 种）。

变更

  • "重新开始监听"按钮现在会说明何时使用：快捷方式原本能用后来失效时。

1.0.9

2026-11-12发布页#1

新增

  • 每个手势一个快捷方式（#1）：单击、双击、三击和长按现在可以各自打开不同的内容。在主屏幕上选一个手势，再选它要打开什么。"移除"会清空该手势。
  • 主屏幕底部新增"重新开始监听"按钮，按键不再响应时可以把它找回来。
  • 当 ColorOS 已把长按用于自己的操作（响铃模式、手电筒等）时，长按标签页会给出提示。

变更

  • 一连串短按只有在更长的连按会打开内容时才会等待零点几秒；否则立即触发。
  • 你当前的快捷方式会保留在你原来选择的手势上。

1.0.8

2026-10-21发布页

新增

  • 复制诊断信息（菜单，或每个设置步骤底部的链接）：把手机型号、系统版本和每一步的状态放进剪贴板，绝不包含你选的应用或链接，可直接粘贴到 GitHub issue（现在有专用表单）。
  • 新增快速设置图块，点开即打开应用，应用在重启后会重新开始监听。

修复

  • 应用和网站中引用的每个 Android 和 ColorOS 菜单名称，现在都与手机系统自带的官方文字一致，涵盖 8 种语言。

1.0.7

2026-10-21发布页

变更

  • 应用一旦设置完成并选好目标（应用、快捷方式或链接），就会自动开始监听。
  • 开始/停止按钮已移除，更改目标或手势会立即生效。
  • 监听期间 Android 要求显示的通知现在是静音的。

1.0.6

2026-10-21发布页

变更

  • 应用设置完成后，监听会自动开始。
  • 最后一个界面会说明可以关闭无线调试。

修复

  • 设置不再卡在"需要 ADB 配对"：配对刚完成时，手机可能暂时还不认识新密钥，因此现在会重试连接。
  • 残留的"正在配对…"通知会被清除。

1.0.5

2026-10-21发布页

新增

  • 配对之前，设置会要求打开 ColorOS 的隐藏开关（"停用系统优化"，仅在手机为英文时显示）。
  • 设置会说明如何展开配对码通知。
  • 新增通知步骤，并在每个自动检查上新增"已经完成，继续"按钮。

修复

  • ColorOS 拒绝权限时，显示清晰的提示，而不是"Stream closed"。
  • 开启 VPN 时也能检测到 Wi-Fi。

1.0.4

2026-10-20发布页

新增

  • 新增一个打开通知的步骤（配对码在其中一条通知里输入）。
  • 每个自动检查上新增"已经完成，继续"按钮，用于误报的手机。

修复

  • 即使开启 VPN 也能检测到 Wi-Fi。
  • 开启 USB 调试时也能找到开发者选项。
  • 手机没有的设置界面会回退到设置主界面。

1.0.3

2026-10-20发布页

新增

  • 引导式设置：每个界面一个步骤，每步都会打开正确的设置并自动进入下一步。

修复

  • 配对后应用会自动回到前台。

1.0.2

2026-10-20发布页

变更

  • 当快捷方式在你的手机上不起作用时，应用现在会说明如何获得帮助：SnapKey Mapper 插件，在通过 adb 连接手机的电脑上使用（USB 数据线或无线调试）。

1.0.1

2026-10-20发布页

变更

  • 当快捷方式在你的手机上不起作用时，每个快捷方式现在都会指向 SnapKey Mapper 插件。
