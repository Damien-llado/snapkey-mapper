OnePlus の Plus Key に好きなアプリを割り当てる

OnePlus スマートフォンの Plus Key で選べる操作は、Mind Space、ライト、着信音モードなど、決まった短い一覧だけです。無料のオープンソースアプリ SnapKey Mapper を使えば、1回押し、2回押し、3回押し、長押しのそれぞれに、好きなアプリやリンクを割り当てられます。

OnePlus が Plus Key にさせてくれること

複数の OnePlus 機種では、Plus Key がアラートスライダーの代わりになっています。スマートフォンの設定で、キーに割り当てる操作を 1 つ選びます。r/oneplus のオーナーが挙げている選択肢は、Mind Space（OnePlus の AI）、ライト、カメラ、スクリーンショット、ボイスレコーダー、翻訳、サイレントモード、そして着信音・バイブ・サイレントの切り替えです。実際の一覧は機種とソフトウェアのバージョンによって異なります。

設定にないのは、本当に使いたいアプリです。オーナーからは、自分のアシスタント、好きなカメラアプリ、2回押しや3回押しで別の操作がほしいという声が出続けています。

アプリでできること

Plus Key ひとつで、ショートカットは 4 つ

押し方ごとに、それぞれ別の対象が開きます。1 つでも、2 つでも、3 つでも、4 つ全部でも設定できます。

  • 4 つの押し方

    1回押し、2回押し、3回押し、長押し（0.5 秒）。連続した押下は、より長い連続押しが設定されているときだけ、区別するために一瞬待ちます。それ以外はすぐに反応します。

  • アプリでもリンクでも

    インストール済みのアプリを選ぶか、リンクを貼り付けるか、Android でできることなら何でも intent: リンクで書けます。キーを押すとそれが開きます。root は不要です。

  • 内蔵アクション

    ライトのオン・オフ、着信音、バイブ、サイレントの順の切り替え、再生または一時停止、次のトラックと前のトラック。何かが開くわけではなく、操作がその場で実行されます。サイレントには「サイレント モード」へのアクセスが必要で、許可は一度だけです。

  • ボイスレコーダー

    ショートカットひとつで、スマートフォンのボイスレコーダーが開き、すぐに音声メモを録れます。

  • ショートカット ライブラリ

    アプリごとにまとめた既製のショートカットで、値ごとの入力欄とテストボタンが付いています。ライブラリを見る。

設定方法

OnePlus で設定する

要点だけをまとめました。詳しいガイドでは、すべての画面と、エラーごとの対処法を紹介しています。

  1. キー本来の操作を外す

    スマートフォンの設定で Plus Key の項目を開きます。「何もしない」の選択肢があればそれを選び、キーが Mind Space やライトを同時に起動しないようにします。OPPO のスマートフォンではシステムがすべての押下をログに記録するので、SnapKey Mapper はそのまま動きます。お使いの OnePlus で挙動が違う場合は、GitHub でお知らせください。

  2. APK をインストールし、制限付き設定を許可する

    APK をダウンロードして開きます。そのあと 設定 › アプリ › SnapKey Mapper を開き、⋮ をタップしてから制限付き設定を許可をタップします。Play ストア以外からインストールしたアプリでは、Android がこれを求めます。

  3. アプリにログの権限を自分で付与させる

    アプリに必要な権限は READ_LOGS の 1 つだけで、Android では root なしで一度だけ付与できます。通常版は、スマートフォン自身のワイヤレス デバッグを使って付与します。このとき一度だけ Wi-Fi が必要ですが、パソコンは不要です。OxygenOS では画面が異なる場合があり、ビルドによっては先に隠しスイッチが必要です。詳しいガイドの手順 3 で説明しています。

  4. 押し方ごとに開くものを選ぶ

    1回押し、2回押し、3回押し、長押しのそれぞれに、アプリ、リンク、内蔵アクションのどれかを選び、起動をテストをタップします。あとはアプリが自動で待機します。

FAQ

Plus Key についてのよくある質問

OnePlus の Plus Key で好きなアプリを開けますか？

OnePlus の設定だけではできません。用意されているのは決まった操作の一覧だけだからです。SnapKey Mapper を使えばできます。インストール済みのどのアプリでも、どのリンクでも開けて、1回押し、2回押し、3回押し、長押しのそれぞれに別のものを設定できます。

Plus Key で 2回押しや3回押しは使えますか？

はい。1回押し、2回押し、3回押し、長押しのそれぞれに、アプリ、リンク、内蔵アクションのいずれかを設定できます。押し方の設定を消すには、アプリでその押し方を選んで削除をタップします。

Plus Key をアラートスライダーとして使えますか？

はい。内蔵アクションの着信音・バイブ・サイレントは、押すたびに次のモードに切り替わります。サイレントには「サイレント モード」へのアクセスが必要で、Android が一度だけ許可を求めます。許可がないと、バイブの次は着信音に戻ります。スマートフォン本来の設定との違いは、押し方を自分で選べて、ほかの押し方を別の用途に使えることです。

Plus Key にライトを割り当てられますか？

はい。内蔵アクションのライトのオン・オフで、ライトがオンになり、点いているときはオフになります。アプリは開きません。

スクリーンショット、サイレントモードの切り替え、かこって検索は使えますか？

内蔵アクションとしては使えません。内蔵アクションは、ライト、着信音・バイブ・サイレント、再生または一時停止、次のトラック、前のトラックです。アプリやリンクから開けるものなら使えますが、スクリーンショットやサイレントモードのスイッチは対象外です。

root、Shizuku、Tasker は必要ですか？

いいえ。アプリに必要な権限は READ_LOGS の 1 つだけで、スマートフォンのワイヤレス デバッグを使って、一度だけ自分で付与します。root も Shizuku も Tasker もユーザー補助サービスも不要です。アプリに何が見えて何が見えないかは、メインの FAQで説明しています。

Plus Key がある OnePlus の機種は？

アプリは OnePlus 15、15R、13s、13T、Nord 5 の Plus Key で使えます。13s と 13T には Plus Key があります。Plus Key があるのに一覧にない場合は、試してみて GitHub でお知らせください。

私の OnePlus で動きません。どうすればいいですか？

アプリでお使いのスマートフォンで動かない？を開いてください。待機を再開し、キーのパターンが変更されていれば元に戻し、機種、システム、バージョンを入れた GitHub の issue を用意します。アプリの「自分でキーを見つける」から、お使いのキーのログの行を送ってもらうこともできます。
