OPPO スマートフォンの Snap Key とは？

Snap Key は、Find X9 シリーズなど一部の OPPO スマートフォンの本体左側面の上部にある物理ボタンです。ColorOS では、AI Mind Space やライトなど、決まった短い一覧の中から 1 つの操作を起動します。無料アプリの SnapKey Mapper を使えば、代わりに好きなアプリやリンクを開けます。

Snap Key の標準の動作

ColorOS 16 の Snap Key でできるのは、OPPO が用意した操作だけです。AI Mind Space、カメラ、ライト、レコーダー、翻訳、スクリーンショット、サウンドモード、サイレントモード。スマートフォンの設定でそのうちの 1 つを選びます。好きなアプリを開く選択肢はありません。

SnapKey Mapper が埋めるのは、まさにこの部分です。キーはそのままに、設定にない機能を加えます。

やりたいことColorOS の設定SnapKey Mapper
インストール済みのアプリを開く一覧にないできる
リンク、ディープリンク、intent を開く一覧にないできる
1回押し、2回押し、3回押し、長押しを使い分けるキーに割り当てられる操作は 1 つ4 つの押し方、それぞれに 1 つの対象
ライト、着信音、バイブ、サイレント一覧にある内蔵アクションを、どの押し方にも

ColorOS の列は、アプリを開発して日常的に使っている OPPO Find X9 Pro の ColorOS 16 の設定を説明しています。ほかの機種やバージョンでは、一覧が異なることがあります。

対応機種

Snap Key があるのはどの機種？

Snap Key は、OPPO の最近のスマートフォンのサイドキーです。Reno 16 シリーズでは AI Snap Key と呼ばれています。OnePlus の一部の機種にも似たキーがあり、Plus Key と呼ばれています。SnapKey Mapper は、下のキーで使えます。

機種キー状態
OPPO Find X9 Pro (ColorOS 16, Android 16)Snap Key動作確認済み、毎日使用
OPPO Find X9, Find X9 Ultra, Find X9s, Find N6Snap KeySnap Key で動作
OPPO Find X10, Find X10 Pro MaxSnap KeySnap Key で動作

お使いの機種で動きませんか？機種名とキーのログの行を添えて、GitHub でお知らせください。

しくみ

ColorOS がロックしているキーをアプリが使えるしくみ

Snap Key を押すたびに、システムログに 1 行（KEYCODE_ACTION_BUTTON_CLICK）が残ります。SnapKey Mapper はログを読み、その行を見つけて、選んだアプリやリンクを開きます。必要な権限は READ_LOGS の 1 つだけで、Android では root なしで一度だけ付与できます。ユーザー補助サービスは使わず、アプリは何も収集しません。

ホームページの「安心してインストール」のセクションに、アプリにできることとできないことをまとめています。

FAQ

Snap Key についてのよくある質問

スナップキー（Snap Key）とは？

一部の OPPO スマートフォンの本体左側面の上部にある物理ボタンです。設定では、決まった一覧から 1 つの操作を選びます。SnapKey Mapper を使えば、好きなアプリやリンクが開き、1回押し、2回押し、3回押し、長押しのそれぞれに別のものを割り当てられます。

Snap Key は OnePlus の Plus Key と同じものですか？

同じグループのスマートフォンにある、よく似たサイドキーです。SnapKey Mapper は両方で使えます。OnePlus の Plus Key のページをご覧ください。

Reno 16 の AI Snap Key とは？

OPPO Reno 16、Reno 16 Pro、Reno 16 F が、サイドキーにつけている名前です。アプリはこのキーでも使えます。反応しない場合は、GitHub でお知らせください。

Snap Key で好きなアプリを開けますか？

OPPO の設定だけではできません。用意されているのは決まった操作の一覧だけです。SnapKey Mapper を使えばできます。インストール済みのどのアプリでも、どのリンクでも開けます。

Snap Key という名前の別の製品と関係がありますか？

いいえ。この名前は、キーボードの機能やゲームの設定など、無関係なものにも使われています。このページで扱うのは、OPPO スマートフォンのサイドキーだけです。
