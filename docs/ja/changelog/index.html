1.0.13 最新

2026-11-13リリース

追加

  • ショートカットライブラリにスマートフォンの操作を追加：ライトのオン・オフ、着信音・バイブ・サイレント、再生または一時停止、次と前のトラック。何も開きません。サイレントには「サイレント モード」へのアクセスを一度だけ許可する必要があります（ショートカットで該当画面が開きます）。
  • ボイスレコーダーのショートカット：スマートフォンのボイスレコーダーを開きます。

変更

  • ショートカットライブラリ：各アプリにお使いのスマートフォンの本物のアイコンを表示します（インストール済みのアプリ、またはタイマー、カメラ、通話などの Android 機能では、それを担当するアプリ）。アプリが未インストールのときだけ内蔵のロゴを表示します。

1.0.12

2026-11-13リリース

変更

  • 「スマートフォンで動かない？」は、よくある解決策から始まるようになりました。待機を再開と、キーのパターンが変更されている場合は元のパターンに戻す。問題の報告は最後です。
  • キー検出: 行をタップしても、動いているパターンを確認なしに置き換えなくなりました。確認画面に現在のパターンと新しいパターンが表示されます。
  • キー検出: 行にキーコード（KEYCODE_…）が含まれる場合、それが提案されるパターンになります。
  • キー検出: パターンの入力欄がキーボードの上に表示されたままになります。
  • キー検出に、OPPO の Snap Key と OnePlus の Plus Key は登録済みと表示されます。

1.0.11

2026-11-13リリース

追加

  • ホーム画面の下部と各セットアップ手順の下部に「お使いのスマートフォンで動かない？」を追加。選択肢は2つです。キーファインダーで自分でキーを見つけて共有する（機種名、システム、選んだ行だけを添えた GitHub の issue が開き、キャプチャのほかの部分は含まれません）か、私たちに任せる（診断情報があらかじめ入力された GitHub の issue が開き、投稿前に内容を確認できます）。

変更

  • 診断に端末の販売名（「OPPO Find X9 Pro」）と、OnePlus では OxygenOS のバージョンが表示されるようになりました。
  • キーファインダーが、キャプチャした行はタップできることを案内し、保存したキーを下部のバーで知らせるようになりました。

1.0.10

2026-11-12リリース

追加

  • 言語を5つ追加：インドネシア語、イタリア語、日本語、ベトナム語、タイ語（合計13言語）。

変更

  • 「待機を再開」ボタンに、使う場面（以前は動いていたショートカットが止まったとき）を表示するようにしました。

1.0.9

2026-11-12リリース#1

追加

  • ジェスチャーごとにショートカットを設定可能に（#1）：1回、2回、3回、長押しでそれぞれ別のものを開けます。ホーム画面でジェスチャーを選び、開く対象を選びます。「削除」でジェスチャーを空にできます。
  • キーが反応しなくなったときに復帰させる「待機を再開」ボタンをホーム画面の下部に追加。
  • ColorOS がすでに長押しを独自の動作（着信モード、ライトなど）に使っている場合、長押しタブに案内を表示します。

変更

  • 短押しの連続は、より長い連続に割り当てがある場合にだけ数分の1秒待ち、それ以外はすぐに実行されます。
  • 現在のショートカットは、選んでいたジェスチャーに引き継がれます。

1.0.8

2026-10-21リリース

追加

  • 診断情報のコピー（メニュー、または各セットアップ手順の下部のリンク）：機種名、システムのバージョン、各手順の状態をクリップボードにコピーします。選んだアプリやリンクは含まれず、そのまま GitHub の issue に貼り付けられます（専用フォームも用意しました）。
  • アプリを開くクイック設定タイルを追加。再起動後でも、アプリが再び待機を始めます。

修正

  • アプリとサイトで引用している Android と ColorOS のメニュー名を、端末自身のシステムの公式表記に合わせました（8言語）。

1.0.7

2026-10-21リリース

変更

  • セットアップが終わり、対象（アプリ、ショートカット、リンク）を選ぶと、アプリが自動で待機を始めます。
  • 開始/停止ボタンを廃止。対象やジェスチャーの変更はすぐに反映されます。
  • 待機中に Android が要求する通知を無音にしました。

1.0.6

2026-10-21リリース

変更

  • アプリのセットアップが済むと、待機が自動で始まります。
  • 最後の画面で、ワイヤレスデバッグをオフにしてよいことを案内します。

修正

  • セットアップが「ADB ペア設定が必要です」で止まる問題を修正：ペア設定の直後は端末が新しいキーをしばらく認識しないことがあるため、接続を再試行します。
  • 残っていた「ペア設定中…」の通知を消去します。

1.0.5

2026-10-21リリース

追加

  • ペア設定の前に、ColorOS の隠しスイッチ（「システム最適化を無効にする」、端末が英語のときだけ表示）を求めます。
  • ペア設定コードの通知を展開する方法を案内します。
  • 通知の手順を追加し、各自動チェックに「設定済み、続ける」ボタンを追加。

修正

  • ColorOS が権限を拒否したとき、「Stream closed」の代わりに分かりやすいメッセージを表示します。
  • VPN がオンでも Wi-Fi を検出します。

1.0.4

2026-10-20リリース

追加

  • 通知をオンにする手順を追加（ペア設定コードは通知のひとつに入力します）。
  • 各自動チェックに「設定済み、続ける」ボタンを追加。誤って報告する端末向けです。

修正

  • VPN がオンでも Wi-Fi を検出します。
  • USB デバッグがオンでも開発者向けオプションを見つけられます。
  • 端末にない設定画面は、設定のトップ画面に切り替えます。

1.0.3

2026-10-20リリース

追加

  • ガイド付きセットアップ：1画面1手順で、各手順が適切な設定を開き、自動で次へ進みます。

修正

  • ペア設定のあと、アプリが自動で前面に戻ります。

1.0.2

2026-10-20リリース

変更

  • ショートカットがお使いの端末で動かないとき、アプリが助けを得る方法を案内します：adb（USB ケーブルまたはワイヤレスデバッグ）で端末とつないだパソコンから使う SnapKey Mapper プラグイン。

1.0.1

2026-10-20リリース

変更

  • ショートカットがお使いの端末で動かないとき、各ショートカットが SnapKey Mapper プラグインを案内します。
