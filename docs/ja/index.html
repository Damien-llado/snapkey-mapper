Claude Code と一緒に

起動できるものなら、Claude Code がキーに割り当ててくれる

ほとんどのアプリはリンクで開けますが、そのリンクを覚えている人はいません。Snap Key に何をさせたいか Claude Code に伝えてください。ディープリンクを見つけ、ADB 経由でスマートフォン上でテストし、SnapKey Mapper に貼り付ける 1 行を教えてくれます。

  • 目的のアプリと画面に合ったリンクを見つける
  • スマートフォンの設定に触れる前にテストする
  • まだリンクがないときは、裏で動く Webhook やショートカットを書く
  • SnapKey Mapper のインストールと権限の付与まで代わりにできる

Claude Code に SnapKey Mapper プラグインを追加：

/plugin install snapkey-mapper --marketplace Damien-llado/snapkey-mapper

Claude Code はパソコン上で動きます。スマートフォンでリンクをテストするには、USB ケーブルで接続する（USB デバッグをオン）か、同じ Wi-Fi でワイヤレス デバッグを使います。接続しなくても Claude はリンクを見つけられるので、アプリのテストボタンで確認してください。

きっかけはこうです。作者は自宅のサーバーで Claude Code を動かし、スマートフォンから Remote Control で話しかけています。OPPO の設定ではその会話を開けず、Key Mapper も Wi-Fi がオンのときしか開けませんでした。そこでこのアプリを作り、2026 年 10 月から毎日使っています。

claude

Snap Key で、クライミングジムまでの自転車ナビを始めたい。

Google マップはナビ用のリンクに対応しています。スマートフォンでテストします：

adb shell am start -a android.intent.action.VIEW \
  -d "google.navigation:q=Climbing+Gym+Lyon&mode=b"

ナビが始まりました。このリンクを SnapKey Mapper に貼り付けてください：

google.navigation:q=Climbing+Gym+Lyon&mode=b

ショートカット ライブラリ

リンクがわからない？ショートカットから選ぶ

アプリには、アプリごとにまとめた既製のショートカットのライブラリが入っています。タイマーの開始、アラームの設定、カメラの起動、電話、メッセージ、目的地へのナビ、プレイリストやチャットを開く、など。1 つ選んで値を入力し、テストしてキーに使うだけです。

  • アプリごとに、公式ロゴ付きで整理
  • 値ごとに入力欄があり、どこで見つけるかのヒント付き
  • 完成したリンクをその場でプレビュー、コピーとテストのボタン付き
  • すべてのショートカットを Android エミュレーターで確認済み、説明している公式ページへのリンク付き

エミュレーターで確認済みでも、すべての機種で動くとは限りません。ColorOS では時計、カメラ、設定のアプリが異なり、アカウントが必要なアプリもあります。各ショートカットのテストボタンを押せば、すぐにわかります。

しくみ

どう動くのか、正直に

ColorOS 16 の Snap Key でできるのは、OPPO が用意した操作だけです。AI Mind Space、カメラ、ライト、レコーダー、翻訳、スクリーンショット、サウンドモード、おやすみモード。「アプリを開く」という選択肢はなく、キー割り当てアプリも、デバッグ接続をオンにし続けないとキーを検出できません。SnapKey Mapper は、ColorOS がすでに記録している内容を見ることで、この制約を回避します。

  • ColorOS はキーが押されるたびに記録する

    システムログに KEYCODE_ACTION_BUTTON_CLICK を含む行が書き込まれます。SnapKey Mapper はログを読み、その行を見つけると、選んだアプリやリンクを開きます。

  • root もユーザー補助も不要

    ログを読むには READ_LOGS という権限が 1 つ必要で、コマンド 1 回で一度だけ付与します。再起動しても残ります。

  • データ収集なし

    アプリにはアカウントも、トラッカーも、広告もありません。保存するのは、設定した対象、キーの名前、押し方だけで、すべてスマートフォンの中です。lite 版はインターネットの権限をまったく持たないため、アプリ自身がネットワークに接続することを Android が許しません。

安心してインストール

Android が表示する警告と、心配いらない理由

SnapKey Mapper は Google Play にないため、Android がいくつか確認を求めます。ウェブサイトからインストールするアプリなら、どれでも同じです。正確な文言は機種によって異なります。

  1. ファイルが有害な可能性があるという警告（Chrome）。ウェブからダウンロードしたすべての APK で表示されます。ダウンロードを確定してください。
  2. 「不明なアプリのインストール」。ブラウザやファイル管理アプリにアプリのインストールを許可するよう求められます。許可してインストールし、気になるならあとでオフに戻してください。
  3. 「Play プロテクトでまだ確認されていないアプリです」。新しいアプリなので、Google がスキャンを提案します。アプリをスキャンをタップすれば、数秒で終わります。
  4. 「有害なアプリをブロックしました」。Google Play プロテクトがこのメッセージを表示し、インストールを止めることがあります。アプリが Google Play ではなく GitHub から配布され、Google がまだ確認していないデベロッパーが機密性の高い権限（システムログの読み取り、他のアプリの上に重ねて表示）を求めているためです。アプリが悪意のあるものと判定されたわけではありません。続ける前に、APK の署名証明書の SHA-256 が a4a6d83d2298e8a88a6da748a3cc9ae9051e459a1d6e06b098a27d2b87f8f796 であることを確認してください（AppVerifier か apksigner verify --print-certs で）。一致すれば、インストールするをタップします。
  5. 「他のアプリの上に重ねて表示」をオンにできない。アプリの制限付き設定を許可するまで、Android がこの権限を拒否することがあります：アプリ情報 › ⋮ › 制限付き設定を許可。そのあと戻って許可してください。

できること

  • システムログを読む（コマンド 1 回で許可したあとだけ）
  • 選んだアプリやリンクを開く
  • 待機中に通知を 1 つ表示する

できないこと

  • 外部への送信：lite 版にはインターネットの権限がなく、通常版も初期設定中に一度、あなたのスマートフォン自身とやり取りするためだけに使います
  • メッセージ、通知、画面へのアクセス：そのための権限を持っていません（システムログは読みます。FAQ を参照）
  • 広告の表示、トラッキング、アカウントの要求

ダウンロードは GitHub のリリースからだけにしてください。ネットワークをまったく使えないアプリがいいなら、同じページから lite 版を入手してください（snapkey-mapper-lite.apk、約 500 KB、インターネットの権限なし）。ログの権限は自分で付与します（手順 3 を参照）。各リリースには APK の SHA-256 と署名証明書のフィンガープリントが載っているので、AppVerifier でファイルを確認できます。ソースコードはすべて公開されています。

設定方法

6 つの手順で設定

約 10 分、最初に一度だけ。Wi-Fi が必要なのは手順 3 だけです。

  1. OPPO 標準の Snap Key の操作をなしにする

    設定 › Snap Key で、キーの操作をなしにして、AI Mind Space やライトが起動しないようにします。ColorOS はその後もすべての押下を記録するので、SnapKey Mapper はそのまま動きます。

  2. APK をインストールし、制限付き設定を許可する

    APK をダウンロードして開きます。Play ストア以外からインストールしたアプリでは、Android が一部の機密性の高い設定をブロックします。設定 › アプリ › SnapKey Mapper を開き、⋮ をタップしてから制限付き設定を許可をタップします。

  3. アプリにログの権限を自分で付与させる

    ColorOS では、隠しスイッチがオンになるまで権限がブロックされます。このスイッチはスマートフォンが英語のときにしか表示されません。まずスマートフォンを English に切り替え（設定 › システムおよび更新 › 言語と地域）、設定で Disable system を検索して Disable system optimisation をオンにします（Turn on anyway をタップ）。言語はすぐに元に戻してかまいません。次に Wi-Fi に接続し、アプリでワイヤレス デバッグを開くをタップします。設定 › システムおよび更新 › 開発者オプションで、ワイヤレス デバッグの行（スイッチではなく文字）をタップしてオンにし、ペア設定コードによるデバイスのペア設定をタップします。通知を引き下ろして展開し、コードを入力をタップして 6 桁の数字を入力します。設定が完了したと通知に表示されたら、ワイヤレス デバッグをオフにします。

    パソコンを使う場合、または lite 版

    lite 版はインターネットの権限がなく、自動では設定できません。パソコンから、またはスマートフォンで Key Mapper（エキスパートモード、Shell command アクション、ADB、そして Test）を使って、次のコマンドを実行してください。あとで Disable system optimisation をオフに戻してもかまいません。権限は残ります。

    adb shell pm grant io.github.damienllado.snapkeymapper android.permission.READ_LOGS

  4. 他のアプリの上に重ねて表示とバッテリーを許可する

    SnapKey Mapper で他のアプリの上に重ねて表示（Android がバックグラウンドからアプリを開けるようにする設定）とバッテリー制限なしをタップします。ColorOS では、アプリのバッテリー使用量も制限なしに設定し、最近のアプリで SnapKey Mapper をロックしてください。

  5. Snap Key で開くものを選ぶ

    インストール済みのアプリを選ぶか、リンク（ウェブアドレス、ディープリンク、intent: リンク）を貼り付けます。次に、使いたい押し方ごとに対象を設定します。1回押し（いちばん速い）、2回押し（ポケットの中で押してしまっても何も開かない）、3回押し、長押し（0.5 秒）。起動をテストをタップして、開くかどうか確認します。押し方ごとに別のものを開けます。連続した押下は、より長い連続押しが設定されているときだけ、区別するために一瞬待ちます。それ以外はすぐに反応します。

  6. あとは自動で待機

    何かを選んだ時点で SnapKey Mapper は待機を始め、起動の操作はいりません。Android 13 以降では「SnapKey Mapper にすべてのデバイスログへのアクセスを許可しますか？」と表示されるので、1 回限りのアクセスを許可を選びます。このアクセスは待機が続く限り有効なので、次に表示されるのは再起動後だけです（「SnapKey Mapper は停止中」の通知をタップ）。ワイヤレス デバッグはもうオフにしてかまいません。

セキュリティのヒント。終わったら、開発者オプションでワイヤレス デバッグをオフにしてください。SnapKey Mapper には不要で、設定の直後に自分のペア設定キーを削除します。そのあと、ワイヤレス デバッグ › ペア設定済みのデバイス から SnapKey Mapper を削除してください。設定は信頼できる Wi-Fi ネットワークでだけ行ってください。

FAQ

よくある質問

Find X9 Pro の Snap Key で好きなアプリを開けますか？

OPPO の設定だけではできません。ColorOS には決まった操作の一覧しかないからです。SnapKey Mapper を使えばできます。インストール済みのどのアプリでも、どのリンクでも開けて、1回押し、2回押し、3回押し、長押しのそれぞれに別のものを設定できます。

1回押し、2回押し、3回押し、長押しに別々の操作を設定できますか？

はい、バージョン 1.0.9 から。3回押しも含め、押し方ごとにアプリかリンクを 1 つずつ設定できます。連続した押下は、より長い連続押しが設定されているときだけ、区別するために一瞬待ちます。それ以外はすぐに反応します。押し方の設定を消すには、アプリでその押し方を選んで削除をタップします。

root は必要ですか？

いいえ。必要な権限は READ_LOGS の 1 つだけで、Android では ADB コマンドで付与できます。root もブートローダーのアンロックも不要です。

パソコンは必要ですか？

いいえ。アプリがスマートフォン自身のワイヤレス デバッグを使って、一度だけ自分で権限を設定します。adb が使えるパソコンでも設定でき、lite 版はこの方法で設定します。

ずっと Wi-Fi が必要ですか？

いいえ。Wi-Fi が必要なのは、権限を付与するためのワイヤレス デバッグで一度だけです。SnapKey Mapper はモバイルデータでも、Wi-Fi オフでも動き続けます。

なぜ「Disable system optimisation」が必要なのですか？

これがないと、ColorOS は pm grant コマンドを拒否します（「Neither user 2000 nor current process has GRANT_RUNTIME_PERMISSIONS」）。オンにして権限を付与し、気になるならまたオフに戻してください。

安全ですか？アプリには何が見えますか？

READ_LOGS を持つアプリはシステムログを読めます。ログにはほかのアプリの情報が含まれることがあります。だからこそ、私たちの言葉をうのみにせず、確かめてください。アプリは何も収集せず、トラッカーもアカウントもありません。lite 版にはインターネットの権限がなく、Android がネットワークの使用をすべてブロックします。これは AppVerifier で確認できます。通常版がこの権限を宣言しているのは、初期設定中にあなたのスマートフォン自身とやり取りするためだけです。ネットワークを扱うコードは短いファイル 1 つにまとまっていて、設定後にアプリのネットワークを遮断することもできます。ソースは公開され、各リリースに SHA-256 と署名のフィンガープリントが載っており、自分でビルドすることもできます。安心してインストールを参照してください。

なぜ Android がまたログへのアクセスを求めるのですか？

Android 13 以降、ログを読む新しいセッションのたびに同意が必要で、しかもアプリが画面に表示されているときしか求められません。SnapKey Mapper はセッションを 1 つ開いたままにするので、また答えるのは再起動後か、システムがアプリを停止したときだけです。

再起動したら Snap Key が反応しなくなった

「SnapKey Mapper は停止中」の通知をタップし、「1 回限りのアクセスを許可」を選んでください。バッテリー使用量が制限なしになっていること、最近のアプリでアプリがロックされていることも確認してください。

ほかの機種でキーの名前を調べるには？

SnapKey Mapper を開いてキャプチャを開始をタップし、キーを 2、3 回押してから停止し、キャプチャを保存します。押すたびに 1 回現れる、KEYCODE_… という名前を含む行を探してください。Find X9 Pro では KEYCODE_ACTION_BUTTON_CLICK（スキャンコード 735）です。

右側のクイックボタンは？

Snap Key は本体左側面の上部にあります。Find X9 Pro の右側面にあるクイックボタンはカメラ操作用で、SnapKey Mapper ではテストしていません。

バッテリーを消耗しますか？

新しいログの行を待つだけで、その間は何もしません。Find X9 Pro での日常使用では消耗は感じられませんでしたが、これは使ってみた感想で、ベンチマークではありません。

Claude Code、ChatGPT、WhatsApp の会話を直接開けますか？

はい、そのアプリが会話へのリンクに対応していれば開けます。リンクを対象として貼り付けてください。対応するアプリがあれば Android がそのアプリで開き、なければブラウザで開きます。

アプリのリンクはどうやって見つけますか？

多くのアプリがリンクを公開しています（Google マップ、Spotify、Home Assistant）。そうでなければ Claude Code やほかのアシスタントに聞き、adb shell am start -a android.intent.action.VIEW -d "<link>" か SnapKey Mapper の起動をテストボタンでリンクをテストしてください。

Google Play で公開されますか？

いいえ。APK は GitHub のリリースからインストールしてください。また Google は、Play ストア以外からインストールするアプリについて、デベロッパーの確認を順次導入しています（一部の国では 2026 年、全世界では 2027 年）。SnapKey Mapper に変更があれば、このページで説明します。

アンインストールするには？

ほかのアプリと同じです。権限も一緒に消えます。ワイヤレス デバッグをオンのままにしていたら、オフにしてください。

OPPO と関係がありますか？

いいえ。SnapKey Mapper は独立したオープンソース プロジェクトで、OPPO、OnePlus、Key Mapper、Anthropic、このページに登場するどのアプリとも提携していません。これらの名前は互換性を示すためだけに使っています。

ショートカット ライブラリとは？

アプリごとにまとめた既製のリンクの一覧です。タイマー、アラーム、カメラ、電話、メッセージ、地図、音楽、チャットなど。アプリから開いてショートカットを選び、空欄を埋めてテストし、Snap Key に使います。各ショートカットには、説明している公式ページへのリンクがあります。

ショートカットが自分のスマートフォンで動くかどうかは？

ショートカットは Android エミュレーターで確認していますが、すべての機種で確認したわけではありません。ColorOS では時計、カメラ、設定のアプリが異なり、アカウントが必要なアプリもあります。各ショートカットのテストボタンを押せば、すぐにわかります。動かないものがあれば、修正か削除ができるよう GitHub でお知らせください。

このサイトはトラッキングしていますか？

このサイトは Microsoft Clarity でアクセスを計測しています（クリック、スクロール、訪問の録画）。ただし、バナーで同意した場合だけです。拒否すると Clarity は読み込まれず、Cookie も設定されません。フッターの「Cookie の設定」から、いつでも変更できます。また、スター数とダウンロード数を api.github.com に問い合わせるため、IP アドレスが GitHub に送られます。数はブラウザに 1 時間保存されます。アプリ自体は何も収集しません。アカウントも、トラッカーも、広告もありません。
