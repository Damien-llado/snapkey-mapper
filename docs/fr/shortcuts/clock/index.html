Comment lancer un minuteur avec la Snap Key OPPO ?

Cinq minutes pour les pâtes, une alarme pour sept heures demain : la touche latérale lance un compte à rebours ou programme une alarme tout de suite, sans ouvrir l’appli Horloge. Vous réglez la durée ou l’heure une fois, dans le raccourci.

Comment

Comment mettre Horloge sur la touche

  1. Installez SnapKey Mapper une fois

    Installez l’appli et donnez-lui l’autorisation de lire les journaux. Le guide d’installation le montre dans une vidéo d’une minute, puis en 6 étapes écrites.

  2. Choisissez l’appui

    Dans l’appli, sous Geste, choisissez Simple, Double, Triple ou Long.

  3. Choisissez un raccourci

    Touchez Parcourir la bibliothèque de raccourcis, tapez Horloge dans le champ de recherche et choisissez l’un des raccourcis ci-dessus. Remplissez vos valeurs, puis touchez Utiliser ce raccourci.

  4. Testez

    Touchez Tester le lancement, puis appuyez sur la touche.

FAQ

Questions

Comment régler la durée du minuteur ?

En secondes, dans le champ du raccourci : 300 pour cinq minutes, 1500 pour vingt-cinq. Chaque appui lance alors un nouveau minuteur de cette durée. Pour deux durées, mettez-en une sur chaque appui.

Puis-je mettre ces raccourcis sur un double appui ou un appui long ?

Oui. Chacun des quatre appuis, simple, double, triple et long, a sa propre cible : un raccourci peut occuper un appui, et autre chose les autres. Si ColorOS utilise déjà l’appui long pour sa propre action, mettez d’abord cette action sur Aucune dans les paramètres du téléphone, sinon les deux se lanceront.

Quelle appli s’ouvre ?

L’appli que votre téléphone utilise par défaut pour cela, celle de ColorOS sur un OPPO, sauf si vous avez choisi une autre appli par défaut dans les paramètres du téléphone.

Comment ces raccourcis ont-ils été testés ?

Chacun a été ouvert sur un émulateur Android, et l’écran attendu s’est affiché. L’émulateur n’est pas un téléphone OPPO : touchez donc une fois Tester le lancement sur le vôtre.

Faut-il rooter le téléphone ?

Non. L’appli a besoin d’une seule autorisation, READ_LOGS, qu’Android permet d’accorder par une commande ADB, sans root et sans déverrouiller le bootloader.
