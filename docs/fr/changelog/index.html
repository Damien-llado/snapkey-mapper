1.0.12 Dernière

2026-11-13Release

Modifications

  • « Ça ne marche pas sur mon téléphone ? » commence par les solutions habituelles : Relancer l'écoute, et Remettre le motif d'origine quand le motif de la touche a été changé. Le signalement d'un problème vient en dernier.
  • Détecteur de touche : toucher une ligne ne remplace plus sans prévenir un motif qui marche. Une confirmation montre le motif actuel et le nouveau.
  • Détecteur de touche : le motif proposé est le code de la touche (KEYCODE_…) quand la ligne en contient un.
  • Détecteur de touche : le champ du motif reste visible au-dessus du clavier.
  • Le détecteur de touche indique que la Snap Key des OPPO et la Plus Key des OnePlus sont déjà connues.

1.0.11

2026-11-13Release

Ajouts

  • Entrée "Ça ne marche pas sur mon téléphone ?" en bas de l'écran d'accueil et de chaque étape de la configuration, avec deux choix : trouver soi-même sa touche avec le détecteur de touche, puis la partager (ouvre une issue GitHub avec le modèle du téléphone, son système et la seule ligne choisie, jamais le reste de la capture), ou nous laisser corriger (ouvre une issue GitHub déjà remplie avec le diagnostic, que vous relisez avant de l'envoyer).

Modifications

  • Le diagnostic indique le nom commercial du téléphone ("OPPO Find X9 Pro") et la version d'OxygenOS sur les OnePlus.
  • Le détecteur de touche précise que les lignes capturées sont cliquables et confirme la touche enregistrée dans la barre du bas.

1.0.10

2026-11-12Release

Ajouts

  • Cinq langues de plus : indonésien, italien, japonais, vietnamien et thaï (13 au total).

Modifications

  • Le bouton "Relancer l'écoute" dit maintenant quand l'utiliser : si les raccourcis marchaient avant et se sont arrêtés.

1.0.9

2026-11-12Release#1

Ajouts

  • Un raccourci par geste (#1) : appui simple, double, triple et long peuvent chacun ouvrir autre chose. Choisissez un geste sur l'écran d'accueil, puis ce qu'il ouvre. "Retirer" efface un geste.
  • Un bouton "Relancer l'écoute" en bas de l'écran d'accueil, pour réveiller la touche si elle ne réagit plus.
  • Un avertissement sur l'onglet Appui long quand ColorOS utilise déjà l'appui long pour sa propre action (mode sonnerie, lampe de poche...).

Modifications

  • Une série d'appuis courts n'attend une fraction de seconde que si une série plus longue ouvre quelque chose ; sinon elle se déclenche tout de suite.
  • Votre raccourci actuel est conservé sur le geste que vous aviez choisi.

1.0.8

2026-10-21Release

Ajouts

  • Copier le diagnostic (menu, ou lien en bas de chaque étape) : place dans le presse-papiers le modèle du téléphone, la version du système et l'état de chaque étape, jamais l'appli ou le lien choisi, prêt à coller dans une issue GitHub (un formulaire existe maintenant).
  • Une tuile des réglages rapides qui ouvre l'appli, laquelle recommence à écouter après un redémarrage.

Corrections

  • Chaque nom de menu Android et ColorOS cité dans l'appli et sur le site correspond désormais au texte officiel du système du téléphone, dans les 8 langues.

1.0.7

2026-10-21Release

Modifications

  • L'appli écoute toute seule dès qu'elle est configurée et qu'une cible (appli, raccourci ou lien) est choisie.
  • Le bouton Démarrer/Arrêter a disparu, et un changement de cible ou de geste s'applique aussitôt.
  • La notification qu'Android impose pendant l'écoute est désormais silencieuse.

1.0.6

2026-10-21Release

Modifications

  • L'écoute démarre toute seule une fois l'appli configurée.
  • Le dernier écran indique que le débogage sans fil peut être désactivé.

Corrections

  • La configuration ne s'arrête plus sur "Appairage ADB requis" : juste après l'appairage, le téléphone peut ne pas connaître la nouvelle clé un instant, la connexion est donc retentée.
  • La notification "Appairage..." qui restait est effacée.

1.0.5

2026-10-21Release

Ajouts

  • La configuration demande l'interrupteur caché de ColorOS avant l'appairage ("Désactiver l'optimisation du système", affiché seulement quand le téléphone est en anglais).
  • La configuration explique comment déplier la notification du code d'appairage.
  • Une étape pour les notifications, et un bouton "C'est déjà fait, continuer" sur chaque vérification automatique.

Corrections

  • Un message clair à la place de "Stream closed" quand ColorOS refuse la permission.
  • Le Wi-Fi est détecté même avec un VPN actif.

1.0.4

2026-10-20Release

Ajouts

  • Une étape qui active les notifications (le code d'appairage se saisit dans l'une d'elles).
  • Un bouton "C'est déjà fait, continuer" sur chaque vérification automatique, pour les téléphones qui se trompent.

Corrections

  • Le Wi-Fi est détecté même avec un VPN actif.
  • Les options pour les développeurs sont aussi trouvées quand le débogage USB est activé.
  • Un écran de réglages que le téléphone n'a pas renvoie vers l'écran principal des Réglages.

1.0.3

2026-10-20Release

Ajouts

  • Configuration guidée : une étape par écran, chacune ouvre le bon réglage et passe à la suivante toute seule.

Corrections

  • L'appli revient toute seule au premier plan après l'appairage.

1.0.2

2026-10-20Release

Modifications

  • Quand un raccourci ne marche pas sur votre téléphone, l'appli indique maintenant comment obtenir de l'aide : le plugin SnapKey Mapper, utilisé depuis un ordinateur relié au téléphone par adb (câble USB ou débogage sans fil).

1.0.1

2026-10-20Release

Modifications

  • Chaque raccourci renvoie maintenant vers le plugin SnapKey Mapper quand il ne marche pas sur votre téléphone.
