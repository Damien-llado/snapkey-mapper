Dengan Claude Code

Jika bisa dijalankan, Claude Code bisa menghubungkannya ke tombol

Sebagian besar aplikasi bisa dibuka lewat tautan, tapi tidak ada yang hafal tautan-tautan itu. Tanyakan ke Claude Code apa yang Anda ingin Snap Key lakukan. Claude Code mencari deep link-nya, mengujinya di ponsel Anda lewat ADB, lalu memberi Anda baris untuk ditempel di SnapKey Mapper.

  • Mencari tautan yang tepat untuk aplikasi dan layar yang Anda inginkan
  • Mengujinya sebelum Anda menyentuh pengaturan ponsel
  • Menulis webhook atau pintasan di baliknya jika belum ada tautannya
  • Bahkan bisa menginstal SnapKey Mapper dan memberinya izin untuk Anda

Tambahkan plugin SnapKey Mapper ke Claude Code:

/plugin install snapkey-mapper --marketplace Damien-llado/snapkey-mapper

Claude Code berjalan di komputer Anda. Untuk menguji tautan di ponsel, sambungkan ponsel dengan kabel USB (Proses debug USB aktif) atau dengan Proses debug nirkabel di Wi-Fi yang sama. Tanpa itu pun, Claude tetap menemukan tautannya, dan Anda memeriksanya dengan tombol uji di aplikasi.

Kasus yang memulai semuanya: pembuatnya menjalankan Claude Code di server rumah dan berbicara dengannya dari ponsel lewat Remote Control. Pengaturan OPPO tidak bisa membuka percakapan itu, dan Key Mapper hanya bisa saat Wi-Fi menyala. Jadi aplikasi ini dibuat, dan dipakai setiap hari sejak Oktober 2026.

Pustaka pintasan

Tidak tahu tautannya? Pilih pintasan

Aplikasi ini dilengkapi pustaka pintasan siap pakai, dikelompokkan per aplikasi: memulai timer, menyetel alarm, membuka kamera, menelepon nomor, menulis pesan, bernavigasi ke suatu tempat, membuka playlist atau chat. Pilih satu, isi nilainya, uji, lalu pakai untuk tombol.

  • Dikelompokkan per aplikasi, dengan logo resmi
  • Satu kolom per nilai, dengan petunjuk di mana menemukannya
  • Pratinjau langsung tautan akhir, dengan tombol salin dan uji
  • Setiap pintasan diperiksa di emulator Android, dengan tautan ke halaman resmi yang menjelaskannya

Diperiksa di emulator belum tentu diperiksa di setiap ponsel: aplikasi jam, kamera, dan pengaturan berbeda di ColorOS, dan beberapa aplikasi perlu akun. Tombol uji di setiap pintasan memberi tahu Anda dengan sekali ketuk.

Tombolnya

Apa itu tombol Snap Key di OPPO dan apa fungsinya?

Snap Key adalah tombol di sisi kiri atas sebagian ponsel OPPO. ColorOS hanya memberinya daftar fungsi yang tetap, seperti AI Mind Space atau senter. SnapKey Mapper berfungsi dengan Snap Key pada OPPO Find X9, X10, Reno 16 dan Find N6, serta dengan Plus Key pada ponsel OnePlus. Saya memakainya setiap hari di Find X9 Pro. SnapKey Mapper menambahkan penyesuaian yang selama ini tidak ada. Baru mengenalnya? Baca apa itu Snap Key dan fungsinya, atau pilih dari 12 ide pintasan. Ingin mencobanya? Langsung ke langkah penyiapan.

Di balik layar

Cara kerjanya, apa adanya

Di ColorOS 16, Snap Key hanya bisa melakukan yang disediakan OPPO: AI Mind Space, kamera, senter, perekam, terjemahan, tangkapan layar, mode suara, atau jangan ganggu. Tidak ada opsi "buka aplikasi", dan aplikasi pengubah tombol tidak bisa melihat tombol ini kecuali koneksi debug tetap aktif. SnapKey Mapper mengatasinya dengan memantau apa yang sudah dicatat ColorOS.

  • ColorOS mencatat setiap tekanan

    Log sistem mendapat baris berisi KEYCODE_ACTION_BUTTON_CLICK. SnapKey Mapper membaca log, menemukan baris itu, lalu membuka aplikasi atau tautan Anda.

  • Tanpa root, tanpa aksesibilitas

    Membaca log butuh satu izin, READ_LOGS, yang diberikan sekali dengan satu perintah. Izin tetap ada setelah ponsel dimulai ulang.

  • Tidak ada data dikumpulkan

    Di aplikasi: tanpa akun, tanpa pelacak, tanpa iklan. Aplikasi hanya menyimpan target Anda, nama tombol, dan gerakan, di ponsel Anda. Edisi lite sama sekali tidak punya izin internet, jadi Android tidak mengizinkannya membuka koneksi jaringan sendiri.

Aman dipasang

Apa yang akan ditampilkan Android, dan mengapa itu wajar

SnapKey Mapper tidak ada di Google Play, jadi Android menambahkan beberapa pemeriksaan. Itu normal untuk aplikasi apa pun yang dipasang dari situs web. Kata-kata persisnya tergantung ponsel Anda.

  1. Peringatan bahwa file mungkin berbahaya, di Chrome. Muncul untuk setiap APK yang diunduh dari web. Konfirmasi unduhannya.
  2. "Instal aplikasi tidak dikenal". Android meminta Anda mengizinkan browser atau pengelola file untuk memasang aplikasi. Izinkan, pasang, lalu matikan lagi jika mau.
  3. "Play Protect belum pernah melihat aplikasi ini". Aplikasinya baru, jadi Google menawarkan untuk memeriksanya. Ketuk Pindai aplikasi: hanya butuh beberapa detik.
  4. "Aplikasi berbahaya diblokir". Google Play Protect bisa menampilkan pesan ini dan menghentikan pemasangan. Ini terjadi karena aplikasinya berasal dari GitHub, bukan Google Play, dan meminta izin sensitif (membaca log sistem, tampil di atas aplikasi lain) dari developer yang belum diverifikasi Google. Ini bukan temuan bahwa aplikasinya berbahaya. Sebelum lanjut, pastikan sertifikat penandatanganan APK punya SHA-256 a4a6d83d2298e8a88a6da748a3cc9ae9051e459a1d6e06b098a27d2b87f8f796 (dengan AppVerifier, atau apksigner verify --print-certs). Jika cocok, ketuk Tetap instal.
  5. "Tampilkan di atas apl lain" tidak bisa diaktifkan. Android bisa menolak izin ini sampai Anda mengizinkan setelan terbatas untuk aplikasinya: Info aplikasi › ⋮ › Izinkan setelan terbatas. Lalu kembali dan berikan izinnya.

Yang bisa dilakukannya

  • Membaca log sistem, hanya setelah Anda mengizinkannya dengan satu perintah
  • Membuka aplikasi atau tautan yang Anda pilih
  • Menampilkan satu notifikasi selama mendengarkan

Yang tidak bisa dilakukannya

  • Mengirim apa pun keluar: edisi lite tidak punya izin internet; edisi lengkap memakainya hanya untuk berkomunikasi dengan ponsel Anda sendiri, sekali, saat penyiapan
  • Mengakses pesan, notifikasi, atau layar Anda: aplikasi tidak punya izin untuk itu (aplikasi memang membaca log sistem, lihat FAQ)
  • Menampilkan iklan, melacak Anda, atau meminta akun

Unduh hanya dari rilis GitHub. Ingin aplikasi yang sama sekali tidak bisa memakai jaringan? Ambil edisi lite dari halaman yang sama (snapkey-mapper-lite.apk, sekitar 500 KB, tanpa izin internet); izin log Anda berikan sendiri, lihat langkah 3. Setiap rilis mencantumkan SHA-256 APK dan sidik jari sertifikat penandatanganan, jadi Anda bisa memeriksa file dengan AppVerifier. Seluruh kode sumbernya publik.

Penyiapan

Siapkan dalam 6 langkah

Sekitar 10 menit, sekali saja. Wi-Fi hanya diperlukan untuk langkah 3.

  1. Atur aksi bawaan Snap Key OPPO ke tidak ada

    Di Pengaturan › Snap Key, atur tombol agar tidak melakukan apa pun, sehingga tidak lagi memicu AI Mind Space atau senter. ColorOS tetap mencatat setiap tekanan, jadi SnapKey Mapper tetap berfungsi.

  2. Pasang APK dan izinkan setelan terbatas

    Unduh APK dan buka. Android memblokir beberapa setelan sensitif untuk aplikasi yang dipasang di luar Play Store: buka Pengaturan › Aplikasi › SnapKey Mapper, ketuk ⋮ lalu Izinkan setelan terbatas.

  3. Biarkan aplikasi memberi dirinya izin log

    Di ColorOS, sebuah izin tetap diblokir sampai sakelar tersembunyi diaktifkan, dan sakelar itu hanya muncul saat bahasa ponsel English. Pertama, ubah bahasa ponsel ke English (Pengaturan › Sistem & pembaruan › Bahasa & wilayah), lalu di Pengaturan cari Disable system dan aktifkan Disable system optimisation (ketuk Turn on anyway). Anda bisa langsung mengembalikan bahasa Anda setelahnya. Lalu sambungkan ke Wi-Fi dan ketuk Buka Proses debug nirkabel di aplikasi. Di Pengaturan › Sistem & pembaruan › Opsi Pengembang, ketuk baris Proses debug nirkabel (teksnya, bukan sakelarnya), aktifkan, ketuk Sambungkan perangkat dengan kode penyambungan, tarik notifikasi ke bawah, bentangkan, ketuk Masukkan kode dan ketik 6 angkanya. Saat notifikasi menyatakan penyiapan selesai, matikan Proses debug nirkabel.

    Dengan komputer, atau edisi lite

    Edisi lite tidak punya izin internet dan tidak bisa menyiapkan dirinya sendiri: jalankan perintah ini dari komputer, atau dari ponsel dengan Key Mapper (mode Expert, aksi Shell command, ADB, lalu Test). Setelahnya Anda bisa mematikan lagi Disable system optimisation: izinnya tetap ada.

    adb shell pm grant io.github.damienllado.snapkeymapper android.permission.READ_LOGS

  4. Izinkan tampil di atas aplikasi lain dan baterai

    Di SnapKey Mapper, ketuk Tampilkan di atas apl lain (inilah yang membuat Android bisa membuka aplikasi Anda dari latar belakang) dan Baterai tanpa batasan. Di ColorOS, atur juga penggunaan baterai aplikasi ke Tidak dibatasi dan kunci SnapKey Mapper di aplikasi terbaru.

  5. Pilih apa yang dibuka Snap Key

    Pilih aplikasi yang terinstal, atau tempel tautan (alamat web, deep link, atau tautan intent:). Lalu atur target untuk setiap gerakan yang Anda inginkan: tekan sekali (paling cepat), tekan dua kali (tertekan di saku tidak akan membuka apa pun), tekan tiga kali, atau tekan lama (setengah detik), dan ketuk Uji peluncuran untuk memastikan target terbuka. Setiap gerakan bisa membuka hal yang berbeda. Rangkaian tekanan hanya menunggu sepersekian detik jika rangkaian yang lebih panjang diatur, untuk membedakannya; selain itu langsung bereaksi.

  6. Mendengarkan dengan sendirinya

    Begitu sesuatu dipilih, SnapKey Mapper langsung mendengarkan, tanpa perlu dimulai. Android 13 ke atas menanyakan "Izinkan SnapKey Mapper mengakses semua log perangkat?": pilih Izinkan akses satu kali. Akses itu berlaku selama aplikasi mendengarkan, jadi Anda baru melihatnya lagi setelah ponsel dimulai ulang (ketuk notifikasi "SnapKey Mapper berhenti"). Sekarang Anda bisa mematikan Proses debug nirkabel.

Tips keamanan. Setelah selesai, matikan Proses debug nirkabel di Opsi Pengembang. SnapKey Mapper tidak membutuhkannya, dan menghapus kunci penyambungannya sendiri tepat setelah penyiapan. Lalu hapus SnapKey Mapper dari Proses debug nirkabel › Perangkat disambungkan. Lakukan penyiapan hanya di jaringan Wi-Fi yang Anda percaya.

FAQ

Pertanyaan

Bisakah Snap Key membuka aplikasi apa saja di Find X9 Pro?

Tidak hanya dengan pengaturan OPPO: ColorOS menawarkan daftar aksi yang tetap. Dengan SnapKey Mapper, bisa: aplikasi terinstal atau tautan apa pun, dan yang berbeda untuk tekan sekali, dua kali, tiga kali, dan tekan lama.

Bisakah saya mengatur aksi berbeda untuk tekan sekali, dua kali, tiga kali, dan tekan lama?

Bisa, sejak versi 1.0.9: setiap gerakan, termasuk tekan tiga kali, punya targetnya sendiri, aplikasi atau tautan. Rangkaian tekanan hanya menunggu sepersekian detik jika rangkaian yang lebih panjang diatur, untuk membedakannya; selain itu langsung bereaksi. Untuk menghapus gerakan, pilih gerakan itu di aplikasi lalu ketuk Hapus.

Apakah perlu root?

Tidak. Aplikasi butuh satu izin, READ_LOGS, yang bisa Anda berikan di Android dengan perintah ADB, tanpa root dan tanpa membuka kunci bootloader.

Apakah perlu komputer?

Tidak. Aplikasi menyiapkan izinnya sendiri lewat Proses debug nirkabel di ponsel Anda, sekali saja. Komputer dengan adb juga bisa, dan begitulah cara menyiapkan edisi lite.

Apakah Wi-Fi harus selalu menyala?

Tidak. Wi-Fi hanya diperlukan sekali, untuk Proses debug nirkabel yang dipakai memberi izin. SnapKey Mapper tetap berfungsi dengan data seluler dan dengan Wi-Fi mati.

Mengapa "Disable system optimisation" diperlukan?

Tanpanya, ColorOS menolak perintah pm grant ("Neither user 2000 nor current process has GRANT_RUNTIME_PERMISSIONS"). Aktifkan, berikan izinnya, lalu matikan lagi jika mau.

Apakah aman? Apa yang bisa dilihat aplikasi?

READ_LOGS memungkinkan aplikasi membaca log sistem, yang bisa berisi detail dari aplikasi lain. Jadi jangan hanya percaya kata kami, periksa sendiri. Aplikasi tidak mengumpulkan apa pun dan tidak punya pelacak atau akun. Edisi lite tidak punya izin internet: Android memblokir semua penggunaan jaringan, dan Anda bisa memeriksanya dengan AppVerifier. Edisi lengkap mendeklarasikannya hanya untuk berkomunikasi dengan ponsel Anda sendiri saat penyiapan; satu-satunya kode jaringan ada di satu file pendek, dan setelahnya Anda bisa memblokir jaringan untuk aplikasi ini. Kode sumbernya publik, setiap rilis mencantumkan SHA-256 dan sidik jari tanda tangan, dan Anda bisa membuild-nya sendiri. Lihat Aman dipasang.

Mengapa Android meminta akses log lagi?

Sejak Android 13, setiap sesi baru pembacaan log memerlukan persetujuan Anda, dan hanya saat aplikasi tampil di layar. SnapKey Mapper menjaga satu sesi tetap terbuka, jadi Anda baru menjawab lagi setelah ponsel dimulai ulang atau jika sistem menghentikan aplikasi.

Snap Key tidak berfungsi lagi setelah ponsel dimulai ulang

Ketuk notifikasi "SnapKey Mapper berhenti", lalu "Izinkan akses satu kali". Periksa juga bahwa penggunaan baterai diatur ke Tidak dibatasi dan aplikasi dikunci di aplikasi terbaru.

Bagaimana cara menemukan nama tombol saya di ponsel lain?

Buka SnapKey Mapper, ketuk Mulai perekaman, tekan tombol Anda dua atau tiga kali, hentikan, lalu simpan hasilnya. Cari baris yang muncul sekali untuk setiap tekanan, dengan nama KEYCODE_…. Di Find X9 Pro namanya KEYCODE_ACTION_BUTTON_CLICK (scan code 735).

Bagaimana dengan Quick Button di kanan?

Snap Key ada di sisi kiri atas. Quick Button di Find X9 Pro, di tepi kanan, adalah kontrol kamera dan belum diuji dengan SnapKey Mapper.

Apakah boros baterai?

Aplikasi menunggu baris log baru dan tidak melakukan apa pun di antaranya. Tidak ada pemborosan yang terasa dalam pemakaian harian di Find X9 Pro, tapi ini pengamatan, bukan benchmark.

Bisakah membuka percakapan Claude Code, ChatGPT, atau WhatsApp secara langsung?

Bisa, jika aplikasinya menerima tautan ke percakapan itu. Tempel tautannya sebagai target: Android membukanya di aplikasi yang sesuai jika aplikasi itu mendukungnya, jika tidak di browser.

Bagaimana cara menemukan tautan sebuah aplikasi?

Banyak aplikasi mendokumentasikan tautannya (Google Maps, Spotify, Home Assistant). Jika tidak, tanyakan ke Claude Code atau asisten lain, lalu uji tautannya dengan adb shell am start -a android.intent.action.VIEW -d "<link>" atau dengan tombol Uji peluncuran di SnapKey Mapper.

Apakah akan ada di Google Play?

Tidak: pasang APK dari rilis GitHub. Google juga sedang menerapkan verifikasi developer untuk aplikasi yang dipasang di luar Play Store (2026 di beberapa negara, di seluruh dunia pada 2027); halaman ini akan menjelaskan setiap perubahan untuk SnapKey Mapper.

Bagaimana cara mencopotnya?

Seperti aplikasi lain. Izinnya ikut hilang. Matikan Proses debug nirkabel jika masih menyala.

Apakah berafiliasi dengan OPPO?

Tidak. SnapKey Mapper adalah proyek open source independen, tidak berafiliasi dengan OPPO, OnePlus, Key Mapper, Anthropic, atau aplikasi mana pun yang ditampilkan di halaman ini. Nama-nama ini hanya menjelaskan kompatibilitas.

Apa itu pustaka pintasan?

Daftar tautan siap pakai yang dikelompokkan per aplikasi: timer, alarm, kamera, panggilan, pesan, peta, musik, chat, dan lainnya. Buka dari aplikasi, pilih pintasan, isi bagian yang kosong, uji, lalu pakai untuk Snap Key. Setiap pintasan menautkan ke halaman resmi yang menjelaskannya.

Bagaimana saya tahu pintasan berfungsi di ponsel saya?

Pintasan diperiksa di emulator Android, bukan di setiap ponsel. Aplikasi jam, kamera, dan pengaturan berbeda di ColorOS, dan beberapa aplikasi perlu akun. Tombol uji di setiap pintasan memberi tahu Anda dengan sekali ketuk. Jika ada yang gagal di ponsel Anda, beri tahu kami di GitHub agar bisa kami perbaiki atau hapus.
