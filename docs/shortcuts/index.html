OPPO Snap Key shortcuts: what to put on each press

Twelve ideas for the side key, from the flashlight to a smart home dashboard. Each one says what it does, which press suits it and how to set it up in SnapKey Mapper, the free app that lets the key open any app, link or built-in action.

Free · MIT licence · Android 11+ · no root, no accessibility service

Ideas

Pick a use

The first four follow how often owners of OPPO and OnePlus phones mention each use in Reddit threads about the key (r/oneplus and r/Oppo, read in November 2026). That ranking is approximate: it comes from counting mentions, not from a survey, and the threads mix both brands. The rest are ideas the app already covers.

  • Flashlight
  • Ring mode
  • Voice notes
  • AI assistants
  • Music
  • Notes
  • Camera
  • Translate, Shazam
  • Google Wallet
  • Smart home
  • Navigation
  • Timers

A set that works: a single press for the flashlight, a double press for your AI assistant (a press in your pocket never opens it), a triple press for a voice note, a long press for play or pause. The key waits a fraction of a second after a press only when a longer series is set, to tell them apart.

Flashlight

Turns the torch on, or off if it is on. No app opens. It is the use owners name most often, even though the key already offers the flashlight in the settings: what they ask for is the flashlight on one gesture, with other things on the others.

  • Suggested press Single press
  • Set it up Built-in action Flashlight on or off

Ring, vibrate, silent

A stand-in for the alert slider. Each press moves to the next mode: ring, then vibrate, then silent. Android only lets an app switch to silent once you allow Do Not Disturb access, which you do once from the app; without it, vibrate goes back to ring.

  • Suggested press Double press
  • Set it up Built-in action Ring, vibrate, silent, then the shortcut Allow silent mode

Voice notes

Opens the phone's voice recorder, ready for a voice note. It opens the recorder; you still tap record.

  • Suggested press Triple press
  • Set it up Library shortcut Open the voice recorder

AI assistants

Claude, ChatGPT, Gemini or Perplexity instead of OPPO's own assistant. The key opens the app you pick; for Claude the library also has a shortcut for a new chat and one for a new Claude Code session. A shortcut straight into the voice mode of an assistant is not in the library: the key opens the app.

  • Suggested press Double press
  • Set it up Pick the installed app, or the library shortcut New chat for Claude, or Open the voice assistant for the default assistant of the phone

Music

Play or pause what is playing, jump to the next or the previous track, without opening the music app. The key sends what a headset button would send, so Spotify, YouTube Music or a podcast app reacts. You can also open a playlist or an album: the library has shortcuts for Spotify, YouTube Music, Deezer and Apple Music.

  • Suggested press Long press for play or pause, triple press for the next track
  • Set it up Built-in actions Play or pause, Next track, Previous track

Quick notes

Open your notes app in one press. The library has shortcuts for Obsidian (a new note, today's daily note, a line added to the daily note), Notion, Google Docs and Todoist. For Google Keep, pick the app: the key opens it, with no note started.

  • Suggested press Triple press
  • Set it up Library shortcuts of Obsidian, Notion, Google Docs or Todoist, or pick the installed app

Camera

The camera in one press, as a shutter button for the side of the phone. The library opens the default camera in photo or in video mode, or you can pick another camera app.

  • Suggested press Single press
  • Set it up Library shortcuts Open the camera in photo mode or in video mode

Translate and identify a song

Owners ask for Google Translate and Shazam on the key. The key opens the app; it does not start a translation or a song search for you, so you still tap once inside the app.

  • Suggested press Long press
  • Set it up Pick the installed app (no library shortcut yet)

Google Wallet

Owners also ask for their wallet, for a card or a car key. The key opens the Google Wallet app; it does not pay for you.

  • Suggested press Double press
  • Set it up Pick the installed app (no library shortcut yet)

Smart home

Open a Home Assistant dashboard page, the one with the lights or the garage door, straight from the key. To fire a workflow, the library also has a shortcut that calls an n8n webhook: it works as a link, so it opens in the browser rather than running silently in the background.

  • Suggested press Triple press
  • Set it up Library shortcuts Open a dashboard page (Home Assistant) or Run a workflow (webhook) (n8n)

Navigation

Turn-by-turn navigation to a saved place, such as home or the gym, on a press. Google Maps can start it on foot, by bike or by car; Waze can navigate home or to work.

  • Suggested press Long press
  • Set it up Library shortcuts of Google Maps (Navigate to an address) or Waze (Navigate home)

Timers and alarms

A countdown that starts at once, without opening the clock app: five minutes for the pasta, twenty-five for a work session. The library also sets an alarm.

  • Suggested press Long press
  • Set it up Library shortcut Start a timer, with the duration in seconds

How

Where to find these in the app

In SnapKey Mapper, choose a gesture, then pick an installed app, paste a link, or open the library. The library groups ready-made shortcuts by app, with one field per value and a Test button. The built-in actions (flashlight, ring mode, play or pause, next and previous track) are in the library under Phone actions.

Built-in actions came with version 1.0.13 and have not yet been tested on every phone: tap Test after you set one, and if it does not work, use Doesn't work on my phone? in the app to tell us. The changelog lists what each version added.
