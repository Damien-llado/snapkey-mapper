ใช้กับ Claude Code

อะไรที่เปิดได้ Claude Code ก็ผูกเข้ากับปุ่มให้ได้

แอปส่วนใหญ่เปิดได้จากลิงก์ แต่ไม่มีใครจำลิงก์พวกนั้นได้ บอก Claude Code ว่าอยากให้ Snap Key ทำอะไร มันจะหา deep link ทดสอบบนมือถือของคุณผ่าน ADB แล้วให้บรรทัดที่ต้องวางใน SnapKey Mapper

  • หาลิงก์ที่ใช่สำหรับแอปและหน้าจอที่คุณต้องการ
  • ทดสอบก่อนที่คุณจะแตะการตั้งค่ามือถือ
  • เขียน webhook หรือทางลัดที่อยู่เบื้องหลังให้ เมื่อยังไม่มีลิงก์
  • ติดตั้ง SnapKey Mapper และให้สิทธิ์แทนคุณได้ด้วย

เพิ่มปลั๊กอิน SnapKey Mapper ให้ Claude Code:

/plugin install snapkey-mapper --marketplace Damien-llado/snapkey-mapper

Claude Code ทำงานบนคอมพิวเตอร์ของคุณ หากจะทดสอบลิงก์บนมือถือ ให้ต่อมือถือด้วยสาย USB (เปิดการแก้ไขข้อบกพร่อง USB) หรือใช้การแก้ไขข้อบกพร่องผ่าน Wi-Fi บน Wi-Fi เดียวกัน ถ้าไม่ได้ต่อ Claude ก็ยังหาลิงก์ให้ได้ แล้วคุณตรวจสอบด้วยปุ่มทดสอบในแอป

จุดเริ่มต้นของแอปนี้: ผู้สร้างรัน Claude Code บนเซิร์ฟเวอร์ที่บ้าน และคุยกับมันจากมือถือผ่าน Remote Control การตั้งค่าของ OPPO เปิดบทสนทนานั้นไม่ได้ ส่วน Key Mapper เปิดได้เฉพาะตอนเปิด Wi-Fi จึงเขียนแอปนี้ขึ้นมา และใช้ทุกวันตั้งแต่ตุลาคม 2026

คลังทางลัด

ไม่รู้ลิงก์? เลือกทางลัดเอา

แอปมีคลังทางลัดสำเร็จรูป จัดกลุ่มตามแอป: เริ่มจับเวลา ตั้งปลุก เปิดกล้อง โทรออก เขียนข้อความ นำทางไปยังสถานที่ เปิดเพลย์ลิสต์หรือแชต เลือกหนึ่งอัน กรอกค่าของคุณ ทดสอบ แล้วใช้กับปุ่มได้เลย

  • จัดกลุ่มตามแอป พร้อมโลโก้ทางการ
  • ช่องกรอกแยกตามค่า พร้อมคำแนะนำว่าหาได้จากที่ไหน
  • ดูตัวอย่างลิงก์สุดท้ายแบบสด พร้อมปุ่มคัดลอกและทดสอบ
  • ทุกทางลัดตรวจสอบแล้วบนอีมูเลเตอร์ Android พร้อมลิงก์ไปยังหน้าทางการที่อธิบายไว้

ตรวจบนอีมูเลเตอร์ไม่ได้แปลว่าตรวจบนมือถือทุกรุ่น: แอปนาฬิกา กล้อง และการตั้งค่าบน ColorOS ต่างออกไป และบางแอปต้องมีบัญชี ปุ่มทดสอบในแต่ละทางลัดบอกผลได้ในแตะเดียว

เบื้องหลัง

ทำงานอย่างไร แบบตรงไปตรงมา

บน ColorOS 16 ปุ่ม Snap Key ทำได้แค่สิ่งที่ OPPO กำหนดไว้: AI Mind Space กล้อง ไฟฉาย เครื่องบันทึกเสียง แปลภาษา จับภาพหน้าจอ โหมดเสียง หรือห้ามรบกวน ไม่มีตัวเลือก "เปิดแอป" และแอปเปลี่ยนปุ่มก็มองไม่เห็นปุ่มนี้ เว้นแต่จะเปิดการเชื่อมต่อดีบักค้างไว้ SnapKey Mapper แก้ปัญหานี้ด้วยการดูสิ่งที่ ColorOS บันทึกไว้อยู่แล้ว

  • ColorOS บันทึกทุกครั้งที่กด

    บันทึกของระบบจะมีบรรทัดที่มี KEYCODE_ACTION_BUTTON_CLICK SnapKey Mapper อ่านบันทึก เจอบรรทัดนั้น แล้วเปิดแอปหรือลิงก์ของคุณ

  • ไม่ต้องรูท ไม่ใช้การช่วยเหลือพิเศษ

    การอ่านบันทึกต้องใช้สิทธิ์เดียว คือ READ_LOGS ให้ครั้งเดียวด้วยคำสั่งเดียว และยังอยู่หลังรีสตาร์ท

  • ไม่เก็บข้อมูลใดๆ

    ในแอป: ไม่มีบัญชี ไม่มีตัวติดตาม ไม่มีโฆษณา เก็บแค่เป้าหมายของคุณ ชื่อปุ่ม และรูปแบบการกด ไว้ในมือถือของคุณ รุ่น lite ไม่มีสิทธิ์อินเทอร์เน็ตเลย Android จึงไม่ยอมให้มันเปิดการเชื่อมต่อเครือข่ายเอง

ติดตั้งได้อย่างปลอดภัย

สิ่งที่ Android จะแสดง และทำไมไม่ต้องกังวล

SnapKey Mapper ไม่ได้อยู่บน Google Play Android จึงมีการตรวจสอบเพิ่มอีกนิด เป็นเรื่องปกติของทุกแอปที่ติดตั้งจากเว็บไซต์ ข้อความที่เห็นจริงขึ้นอยู่กับมือถือของคุณ

  1. คำเตือนว่าไฟล์อาจเป็นอันตราย ใน Chrome ซึ่งขึ้นกับทุก APK ที่ดาวน์โหลดจากเว็บ ยืนยันการดาวน์โหลด
  2. "ติดตั้งแอปที่ไม่รู้จัก" Android ขอให้คุณอนุญาตเบราว์เซอร์หรือแอปจัดการไฟล์ให้ติดตั้งแอปได้ อนุญาต ติดตั้ง แล้วปิดกลับได้ถ้าต้องการ
  3. "Play Protect ไม่เคยเห็นแอปนี้มาก่อน" แอปยังใหม่ Google จึงเสนอให้ตรวจสอบ แตะ สแกนแอป ใช้เวลาไม่กี่วินาที
  4. "บล็อกแอปที่เป็นอันตรายแล้ว" Google Play Protect อาจแสดงข้อความนี้และหยุดการติดตั้ง ที่เป็นแบบนี้เพราะแอปมาจาก GitHub ไม่ใช่ Google Play และขอสิทธิ์ที่ละเอียดอ่อน (อ่านบันทึกของระบบ แสดงทับแอปอื่นๆ) จากนักพัฒนาที่ Google ยังไม่ได้ยืนยัน ไม่ได้แปลว่าแอปถูกตัดสินว่าเป็นมัลแวร์ ก่อนดำเนินการต่อ ให้ตรวจว่าใบรับรองการลงนามของ APK มี SHA-256 เป็น a4a6d83d2298e8a88a6da748a3cc9ae9051e459a1d6e06b098a27d2b87f8f796 (ด้วย AppVerifier หรือ apksigner verify --print-certs) ถ้าตรงกัน แตะ ติดตั้งต่อไป
  5. เปิด "แสดงทับแอปอื่นๆ" ไม่ได้ Android อาจปฏิเสธสิทธิ์นี้จนกว่าคุณจะอนุญาตสิทธิ์ที่จำกัดให้แอป: ข้อมูลแอปพลิเคชัน › ⋮ › อนุญาตให้เข้าถึงสิทธิ์ที่จำกัด แล้วกลับไปให้สิทธิ์อีกครั้ง

สิ่งที่ทำได้

  • อ่านบันทึกของระบบ หลังจากคุณให้สิทธิ์ด้วยคำสั่งเดียวเท่านั้น
  • เปิดแอปหรือลิงก์ที่คุณเลือก
  • แสดงการแจ้งเตือนหนึ่งรายการระหว่างรอฟัง

สิ่งที่ทำไม่ได้

  • ส่งอะไรออกไปข้างนอก: รุ่น lite ไม่มีสิทธิ์อินเทอร์เน็ต ส่วนรุ่นเต็มใช้แค่เพื่อคุยกับมือถือของคุณเอง ครั้งเดียว ระหว่างตั้งค่า
  • เข้าถึงข้อความ การแจ้งเตือน หรือหน้าจอของคุณ: แอปไม่มีสิทธิ์เหล่านั้น (แต่อ่านบันทึกของระบบ ดู FAQ)
  • แสดงโฆษณา ติดตามคุณ หรือขอให้สมัครบัญชี

ดาวน์โหลดจาก หน้ารีลีสบน GitHub เท่านั้น อยากได้แอปที่ใช้เครือข่ายไม่ได้เลย? เลือกรุ่น lite จากหน้าเดียวกัน (snapkey-mapper-lite.apk ประมาณ 500 KB ไม่มีสิทธิ์อินเทอร์เน็ต) คุณให้สิทธิ์อ่านบันทึกเอง ดูขั้นตอนที่ 3 ทุกรีลีสระบุ SHA-256 ของ APK และลายนิ้วมือของใบรับรองการลงนาม คุณจึงตรวจไฟล์ได้ด้วย AppVerifier ซอร์สโค้ดทั้งหมดเปิดเผยต่อสาธารณะ

ตั้งค่าใน 6 ขั้นตอน

ประมาณ 10 นาที ทำครั้งเดียว ใช้ Wi-Fi แค่ในขั้นตอนที่ 3

  1. ตั้งการทำงานเดิมของ Snap Key ของ OPPO เป็นไม่ทำอะไร

    ใน การตั้งค่า › Snap Key ตั้งปุ่มให้ไม่ทำอะไร เพื่อไม่ให้เรียก AI Mind Space หรือไฟฉายอีก ColorOS ยังบันทึกทุกครั้งที่กด SnapKey Mapper จึงทำงานต่อได้

  2. ติดตั้ง APK และอนุญาตสิทธิ์ที่จำกัด

    ดาวน์โหลด APK แล้วเปิด Android บล็อกการตั้งค่าที่ละเอียดอ่อนบางอย่างสำหรับแอปที่ติดตั้งนอก Play Store: ไปที่ การตั้งค่า › แอป › SnapKey Mapper แตะ ⋮ แล้วแตะ อนุญาตให้เข้าถึงสิทธิ์ที่จำกัด

  3. ให้แอปให้สิทธิ์อ่านบันทึกกับตัวเอง

    บน ColorOS สิทธิ์หนึ่งจะถูกบล็อกจนกว่าจะเปิดสวิตช์ที่ซ่อนอยู่ และสวิตช์นั้นจะแสดงเฉพาะตอนมือถือเป็นภาษาอังกฤษ ขั้นแรก เปลี่ยนภาษามือถือเป็น English (การตั้งค่า › ระบบและการอัพเดต › ภาษาและภูมิภาค) จากนั้นในการตั้งค่า ค้นหา Disable system แล้วเปิด Disable system optimisation (แตะ Turn on anyway) เปลี่ยนภาษากลับได้ทันทีหลังจากนั้น ต่อไปเชื่อมต่อ Wi-Fi แล้วแตะ เปิดการแก้ไขข้อบกพร่องผ่าน Wi-Fi ในแอป ใน การตั้งค่า › ระบบและการอัพเดต › ตัวเลือกสำหรับนักพัฒนาซอฟต์แวร์ แตะบรรทัด การแก้ไขข้อบกพร่องผ่าน Wi-Fi (ที่ตัวหนังสือ ไม่ใช่สวิตช์) เปิดใช้ แตะ จับคู่อุปกรณ์ด้วยรหัสการจับคู่ ดึงแถบการแจ้งเตือนลง ขยายการแจ้งเตือน แตะ ป้อนรหัส แล้วพิมพ์ตัวเลข 6 หลัก เมื่อการแจ้งเตือนบอกว่าตั้งค่าเสร็จแล้ว ให้ปิดการแก้ไขข้อบกพร่องผ่าน Wi-Fi

    ใช้คอมพิวเตอร์ หรือรุ่น lite

    รุ่น lite ไม่มีสิทธิ์อินเทอร์เน็ตและตั้งค่าเองไม่ได้: รันคำสั่งนี้จากคอมพิวเตอร์ หรือจากมือถือด้วย Key Mapper (โหมด Expert การทำงาน Shell command ADB แล้ว Test) หลังจากนั้นปิด Disable system optimisation กลับได้ สิทธิ์ยังอยู่

    adb shell pm grant io.github.damienllado.snapkeymapper android.permission.READ_LOGS

  4. อนุญาตการแสดงทับแอปอื่นและแบตเตอรี่

    ใน SnapKey Mapper แตะ แสดงทับแอปอื่นๆ (สิ่งนี้ทำให้ Android เปิดแอปของคุณจากเบื้องหลังได้) และ แบตเตอรี่แบบไม่จำกัด บน ColorOS ให้ตั้งการใช้งานแบตเตอรี่ของแอปเป็น ไม่จำกัด ด้วย และล็อก SnapKey Mapper ไว้ในแอปล่าสุด

  5. เลือกสิ่งที่ Snap Key จะเปิด

    เลือกแอปที่ติดตั้งไว้ หรือวางลิงก์ (ที่อยู่เว็บ deep link หรือลิงก์ intent:) จากนั้นตั้งเป้าหมายให้แต่ละรูปแบบการกดที่ต้องการ: กดครั้งเดียว (เร็วที่สุด) กดสองครั้ง (กดโดนในกระเป๋าจะไม่เปิดอะไร) กดสามครั้ง หรือกดค้าง (ครึ่งวินาที) แล้วแตะ ทดสอบการเปิด เพื่อตรวจว่าเปิดได้ แต่ละแบบเปิดสิ่งที่ต่างกันได้ การกดต่อเนื่องจะรอเสี้ยววินาทีก็ต่อเมื่อตั้งการกดที่ต่อเนื่องนานกว่าไว้ เพื่อแยกให้ออก ถ้าไม่ได้ตั้งไว้ก็ทำงานทันที

  6. รอฟังเองอัตโนมัติ

    ทันทีที่เลือกอะไรไว้ SnapKey Mapper ก็เริ่มรอฟัง ไม่ต้องสั่งเริ่ม Android 13 ขึ้นไปจะถามว่า "อนุญาตให้ "SnapKey Mapper" เข้าถึงบันทึกทั้งหมดของอุปกรณ์ไหม": เลือก อนุญาตสิทธิ์เข้าถึงแบบครั้งเดียว สิทธิ์นี้อยู่ตลอดที่แอปรอฟัง คุณจึงจะเห็นอีกครั้งหลังรีสตาร์ทเท่านั้น (แตะการแจ้งเตือน "SnapKey Mapper หยุดทำงานอยู่") ตอนนี้ปิดการแก้ไขข้อบกพร่องผ่าน Wi-Fi ได้แล้ว

เคล็ดลับความปลอดภัย เมื่อเสร็จแล้ว ให้ปิดการแก้ไขข้อบกพร่องผ่าน Wi-Fi ในตัวเลือกสำหรับนักพัฒนาซอฟต์แวร์ SnapKey Mapper ไม่ต้องใช้ และจะลบคีย์จับคู่ของตัวเองทันทีหลังตั้งค่า จากนั้นลบ SnapKey Mapper ออกจาก การแก้ไขข้อบกพร่องผ่าน Wi-Fi › อุปกรณ์ที่จับคู่ ทำการตั้งค่าบนเครือข่าย Wi-Fi ที่คุณไว้ใจเท่านั้น

FAQ

คำถามที่พบบ่อย

Snap Key ของ Find X9 Pro เปิดแอปไหนก็ได้ไหม?

ถ้าใช้แค่การตั้งค่าของ OPPO ไม่ได้ ColorOS มีรายการการทำงานที่ตายตัว แต่ถ้าใช้ SnapKey Mapper ได้: แอปที่ติดตั้งไว้หรือลิงก์ไหนก็ได้ และเปิดคนละอย่างสำหรับกดครั้งเดียว กดสองครั้ง กดสามครั้ง และกดค้าง

ตั้งการทำงานต่างกันสำหรับกดครั้งเดียว สองครั้ง สามครั้ง และกดค้างได้ไหม?

ได้ ตั้งแต่เวอร์ชัน 1.0.9: ทุกรูปแบบการกด รวมถึงกดสามครั้ง มีเป้าหมายของตัวเอง เป็นแอปหรือลิงก์ การกดต่อเนื่องจะรอเสี้ยววินาทีก็ต่อเมื่อตั้งการกดที่ต่อเนื่องนานกว่าไว้ เพื่อแยกให้ออก ถ้าไม่ได้ตั้งไว้ก็ทำงานทันที หากจะล้างรูปแบบการกด ให้เลือกในแอปแล้วแตะ ลบออก

ต้องรูทไหม?

ไม่ต้อง แอปต้องการสิทธิ์เดียว คือ READ_LOGS ซึ่ง Android ให้คุณให้สิทธิ์ได้ด้วยคำสั่ง ADB ไม่ต้องรูท และไม่ต้องปลดล็อก bootloader

ต้องใช้คอมพิวเตอร์ไหม?

ไม่ต้อง แอปตั้งค่าสิทธิ์เองผ่านการแก้ไขข้อบกพร่องผ่าน Wi-Fi ของมือถือคุณ ครั้งเดียว คอมพิวเตอร์ที่มี adb ก็ใช้ได้ และรุ่น lite ตั้งค่าด้วยวิธีนี้

ต้องเปิด Wi-Fi ตลอดเวลาไหม?

ไม่ต้อง ใช้ Wi-Fi แค่ครั้งเดียว สำหรับการแก้ไขข้อบกพร่องผ่าน Wi-Fi ที่ใช้ให้สิทธิ์ SnapKey Mapper ยังทำงานได้ผ่านเน็ตมือถือและตอนปิด Wi-Fi

ทำไมต้องใช้ "Disable system optimisation"?

ถ้าไม่เปิด ColorOS จะปฏิเสธคำสั่ง pm grant ("Neither user 2000 nor current process has GRANT_RUNTIME_PERMISSIONS") เปิดไว้ ให้สิทธิ์ แล้วปิดกลับได้ถ้าต้องการ

ปลอดภัยไหม? แอปเห็นอะไรได้บ้าง?

READ_LOGS ทำให้แอปอ่านบันทึกของระบบได้ ซึ่งอาจมีรายละเอียดจากแอปอื่น ดังนั้นอย่าเชื่อแค่คำพูดของเรา ตรวจสอบเอง แอปไม่เก็บข้อมูลใดๆ ไม่มีตัวติดตามหรือบัญชี รุ่น lite ไม่มีสิทธิ์อินเทอร์เน็ต: Android บล็อกการใช้เครือข่ายทั้งหมด และคุณตรวจได้ด้วย AppVerifier รุ่นเต็มประกาศสิทธิ์นี้เพื่อคุยกับมือถือของคุณเองระหว่างตั้งค่าเท่านั้น โค้ดเครือข่ายมีอยู่ในไฟล์สั้นๆ ไฟล์เดียว และหลังจากนั้นคุณบล็อกเครือข่ายของแอปได้ ซอร์สโค้ดเปิดเผย ทุกรีลีสระบุ SHA-256 และลายนิ้วมือของการลงนาม และคุณ build เองได้ ดู ติดตั้งได้อย่างปลอดภัย

ทำไม Android ถึงขอสิทธิ์เข้าถึงบันทึกอีก?

ตั้งแต่ Android 13 ทุกเซสชันใหม่ของการอ่านบันทึกต้องได้รับความยินยอมจากคุณ และถามเฉพาะตอนแอปอยู่บนหน้าจอ SnapKey Mapper เปิดเซสชันค้างไว้หนึ่งเซสชัน คุณจึงต้องตอบอีกครั้งหลังรีสตาร์ท หรือเมื่อระบบหยุดแอปเท่านั้น

Snap Key ใช้ไม่ได้หลังรีสตาร์ท

แตะการแจ้งเตือน "SnapKey Mapper หยุดทำงานอยู่" แล้วเลือก "อนุญาตสิทธิ์เข้าถึงแบบครั้งเดียว" ตรวจด้วยว่าการใช้งานแบตเตอรี่ตั้งเป็นไม่จำกัด และล็อกแอปไว้ในแอปล่าสุดแล้ว

จะหาชื่อปุ่มบนมือถือรุ่นอื่นได้อย่างไร?

เปิด SnapKey Mapper แตะ เริ่มเก็บข้อมูล กดปุ่มของคุณสองหรือสามครั้ง หยุด แล้วบันทึกผล มองหาบรรทัดที่ขึ้นหนึ่งครั้งต่อการกดหนึ่งครั้ง ที่มีชื่อแบบ KEYCODE_… บน Find X9 Pro คือ KEYCODE_ACTION_BUTTON_CLICK (scan code 735)

แล้ว Quick Button ด้านขวาล่ะ?

Snap Key อยู่ด้านซ้ายตอนบน ส่วน Quick Button ของ Find X9 Pro ที่ขอบขวาเป็นปุ่มควบคุมกล้อง และยังไม่ได้ทดสอบกับ SnapKey Mapper

กินแบตไหม?

แอปรอบรรทัดบันทึกใหม่ และไม่ทำอะไรในระหว่างนั้น ใช้งานจริงทุกวันบน Find X9 Pro ไม่พบว่ากินแบต แต่นี่เป็นการสังเกต ไม่ใช่ผลวัดแบบ benchmark

เปิดบทสนทนา Claude Code, ChatGPT หรือ WhatsApp ได้โดยตรงไหม?

ได้ ถ้าแอปนั้นรับลิงก์ไปยังบทสนทนา วางลิงก์เป็นเป้าหมาย: Android จะเปิดในแอปที่ตรงกันถ้าแอปรองรับ ไม่อย่างนั้นจะเปิดในเบราว์เซอร์

จะหาลิงก์ของแอปได้อย่างไร?

หลายแอปมีเอกสารเรื่องลิงก์ (Google Maps, Spotify, Home Assistant) ถ้าไม่มี ให้ถาม Claude Code หรือผู้ช่วยตัวอื่น แล้วทดสอบลิงก์ด้วย adb shell am start -a android.intent.action.VIEW -d "<link>" หรือด้วยปุ่ม ทดสอบการเปิด ใน SnapKey Mapper

จะมีบน Google Play ไหม?

ไม่มี: ติดตั้ง APK จากหน้ารีลีสบน GitHub นอกจากนี้ Google กำลังเริ่มใช้การยืนยันตัวตนนักพัฒนาสำหรับแอปที่ติดตั้งนอก Play Store (ปี 2026 ในบางประเทศ และทั่วโลกในปี 2027) หน้านี้จะอธิบายการเปลี่ยนแปลงใดๆ ที่เกี่ยวกับ SnapKey Mapper

ถอนการติดตั้งอย่างไร?

เหมือนแอปทั่วไป สิทธิ์จะหายไปพร้อมกัน ปิดการแก้ไขข้อบกพร่องผ่าน Wi-Fi ถ้ายังเปิดค้างไว้

เกี่ยวข้องกับ OPPO ไหม?

ไม่ SnapKey Mapper เป็นโปรเจกต์โอเพนซอร์สอิสระ ไม่เกี่ยวข้องกับ OPPO, OnePlus, Key Mapper, Anthropic หรือแอปใดๆ ที่แสดงในหน้านี้ ชื่อเหล่านี้ใช้เพื่อบอกความเข้ากันได้เท่านั้น

คลังทางลัดคืออะไร?

รายการลิงก์สำเร็จรูปที่จัดกลุ่มตามแอป: ตัวจับเวลา นาฬิกาปลุก กล้อง การโทร ข้อความ แผนที่ เพลง แชต และอื่นๆ เปิดจากในแอป เลือกทางลัด กรอกช่องว่าง ทดสอบ แล้วใช้กับ Snap Key ทุกทางลัดมีลิงก์ไปยังหน้าทางการที่อธิบายไว้

จะรู้ได้อย่างไรว่าทางลัดใช้ได้บนมือถือของฉัน?

ทางลัดตรวจสอบบนอีมูเลเตอร์ Android ไม่ใช่บนมือถือทุกรุ่น แอปนาฬิกา กล้อง และการตั้งค่าบน ColorOS ต่างออกไป และบางแอปต้องมีบัญชี ปุ่มทดสอบของแต่ละทางลัดบอกผลได้ในแตะเดียว ถ้ามีอันไหนใช้ไม่ได้บนมือถือของคุณ บอกเราบน GitHub เพื่อให้เราแก้หรือเอาออก

เว็บไซต์วัดผู้เข้าชมด้วย Microsoft Clarity (การคลิก การเลื่อน การบันทึกการเข้าชม) แต่เฉพาะเมื่อคุณยอมรับในแบนเนอร์ ถ้าคุณปฏิเสธ Clarity จะไม่ถูกโหลดและไม่ตั้งคุกกี้ คุณเปลี่ยนใจได้ทุกเมื่อด้วย "ตั้งค่าคุกกี้" ที่ส่วนท้ายของหน้า หน้านี้ยังขอจำนวนดาวและยอดดาวน์โหลดจาก api.github.com ซึ่งส่งที่อยู่ IP ของคุณไปยัง GitHub และเก็บตัวเลขไว้ในเบราว์เซอร์หนึ่งชั่วโมง หน้าติดตั้งฝังวิดีโอ YouTube (youtube-nocookie.com) ไว้ ซึ่งจะโหลดทันทีที่เปิดหน้า ตัวแอปเองไม่เก็บข้อมูลใดๆ: ไม่มีบัญชี ไม่มีตัวติดตาม ไม่มีโฆษณา
