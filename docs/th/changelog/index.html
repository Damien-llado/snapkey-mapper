1.0.13 ล่าสุด

2026-11-13รุ่นที่ปล่อย

เพิ่มใหม่

  • การทำงานของโทรศัพท์ในคลังทางลัด: เปิดหรือปิดไฟฉาย เสียง / สั่น / ปิดเสียง เล่นหรือหยุดชั่วคราว แทร็กถัดไปและก่อนหน้า ไม่มีอะไรเปิดขึ้นมา การปิดเสียงต้องอนุญาตสิทธิ์ "ห้ามรบกวน" หนึ่งครั้ง (มีทางลัดที่เปิดหน้าจอที่ถูกต้อง)
  • ทางลัดเครื่องบันทึกเสียง: เปิดเครื่องบันทึกเสียงของโทรศัพท์

เปลี่ยนแปลง

  • คลังทางลัด: แต่ละแอปแสดงไอคอนจริงบนโทรศัพท์ของคุณ (แอปที่ติดตั้ง หรือสำหรับตัวจับเวลา กล้อง การโทร และฟังก์ชันอื่นของ Android คือแอปที่จัดการสิ่งนั้นบนโทรศัพท์ของคุณ) โลโก้ในตัวจะแสดงเฉพาะเมื่อไม่ได้ติดตั้งแอป

1.0.12

2026-11-13รุ่นที่ปล่อย

เปลี่ยนแปลง

  • "ใช้ไม่ได้บนโทรศัพท์ของฉัน?" เริ่มจากวิธีแก้ที่พบบ่อยก่อน: เริ่มรอฟังใหม่ และคืนค่ารูปแบบเดิมเมื่อรูปแบบของปุ่มถูกเปลี่ยน การแจ้งปัญหาอยู่ท้ายสุด
  • ตัวค้นหาปุ่ม: การแตะบรรทัดจะไม่แทนที่รูปแบบที่ใช้งานได้โดยไม่ถามอีกต่อไป หน้ายืนยันจะแสดงรูปแบบปัจจุบันและรูปแบบใหม่
  • ตัวค้นหาปุ่ม: รูปแบบที่แนะนำคือรหัสปุ่ม (KEYCODE_…) เมื่อบรรทัดมีรหัสนั้น
  • ตัวค้นหาปุ่ม: ช่องรูปแบบยังมองเห็นได้เหนือแป้นพิมพ์
  • ตัวค้นหาปุ่มแจ้งว่าแอปรู้จัก Snap Key ของ OPPO และ Plus Key ของ OnePlus อยู่แล้ว

1.0.11

2026-11-13รุ่นที่ปล่อย

เพิ่มใหม่

  • รายการ "ใช้กับโทรศัพท์ของฉันไม่ได้?" ที่ด้านล่างของหน้าจอหลักและทุกขั้นตอนการตั้งค่า มีสองทางเลือก: หาปุ่มของคุณเองด้วยตัวค้นหาปุ่มแล้วแชร์ (เปิด GitHub issue พร้อมรุ่นโทรศัพท์ ระบบ และเฉพาะบรรทัดที่เลือก ไม่มีส่วนอื่นของข้อมูลที่จับมา) หรือให้เราแก้ให้ (เปิด GitHub issue ที่กรอกข้อมูลวินิจฉัยไว้แล้ว ซึ่งคุณอ่านก่อนส่งได้)

เปลี่ยนแปลง

  • ข้อมูลวินิจฉัยแสดงชื่อทางการค้าของโทรศัพท์ ("OPPO Find X9 Pro") และเวอร์ชัน OxygenOS บนโทรศัพท์ OnePlus
  • ตัวค้นหาปุ่มบอกว่าบรรทัดที่จับมาแตะได้ และยืนยันปุ่มที่บันทึกในแถบด้านล่าง

1.0.10

2026-11-12รุ่นที่ปล่อย

เพิ่มใหม่

  • เพิ่มอีกห้าภาษา: อินโดนีเซีย อิตาลี ญี่ปุ่น เวียดนาม และไทย (รวม 13 ภาษา)

เปลี่ยนแปลง

  • ปุ่ม "เริ่มรอฟังใหม่" บอกแล้วว่าควรใช้เมื่อไร: เมื่อทางลัดเคยใช้ได้แล้วหยุดทำงาน

1.0.9

2026-11-12รุ่นที่ปล่อย#1

เพิ่มใหม่

  • หนึ่งทางลัดต่อหนึ่งท่าทาง (#1): กดครั้งเดียว กดสองครั้ง กดสามครั้ง และกดค้าง เปิดสิ่งที่ต่างกันได้ เลือกท่าทางในหน้าจอหลัก แล้วเลือกสิ่งที่จะเปิด "ลบ" จะล้างท่าทางนั้น
  • ปุ่ม "เริ่มรอฟังใหม่" ที่ด้านล่างของหน้าจอหลัก เพื่อเรียกปุ่มกลับมาเมื่อหยุดตอบสนอง
  • ข้อความแจ้งในแท็บกดค้างเมื่อ ColorOS ใช้การกดค้างกับการทำงานของตัวเองอยู่แล้ว (โหมดเสียงเรียกเข้า ไฟฉาย...)

เปลี่ยนแปลง

  • การกดสั้นต่อเนื่องจะรอเพียงเสี้ยววินาทีเมื่อมีชุดที่ยาวกว่าเปิดบางอย่างอยู่เท่านั้น มิฉะนั้นจะทำงานทันที
  • ทางลัดปัจจุบันของคุณยังอยู่กับท่าทางที่คุณเลือกไว้

1.0.8

2026-10-21รุ่นที่ปล่อย

เพิ่มใหม่

  • คัดลอกข้อมูลวินิจฉัย (เมนู หรือลิงก์ที่ด้านล่างของทุกขั้นตอนการตั้งค่า): ใส่รุ่นโทรศัพท์ เวอร์ชันระบบ และสถานะของแต่ละขั้นตอนลงในคลิปบอร์ด ไม่มีแอปหรือลิงก์ที่คุณเลือก พร้อมวางใน GitHub issue (ตอนนี้มีแบบฟอร์มให้แล้ว)
  • ไทล์การตั้งค่าด่วนที่เปิดแอป ซึ่งจะเริ่มรอฟังอีกครั้งหลังรีบูต

แก้ไขแล้ว

  • ชื่อเมนู Android และ ColorOS ทุกชื่อที่อ้างถึงในแอปและบนเว็บไซต์ ตอนนี้ตรงกับข้อความทางการของระบบในโทรศัพท์เอง ใน 8 ภาษา

1.0.7

2026-10-21รุ่นที่ปล่อย

เปลี่ยนแปลง

  • แอปรอฟังเองทันทีที่ตั้งค่าเสร็จและเลือกปลายทาง (แอป ทางลัด หรือลิงก์) แล้ว
  • ปุ่มเริ่ม/หยุดหายไป และการเปลี่ยนปลายทางหรือท่าทางมีผลทันที
  • การแจ้งเตือนที่ Android กำหนดระหว่างรอฟังตอนนี้เงียบ

1.0.6

2026-10-21รุ่นที่ปล่อย

เปลี่ยนแปลง

  • การรอฟังเริ่มเองเมื่อตั้งค่าแอปเสร็จ
  • หน้าจอสุดท้ายบอกว่าปิดการแก้ไขข้อบกพร่องผ่านไร้สายได้

แก้ไขแล้ว

  • การตั้งค่าไม่ค้างที่ "ต้องจับคู่ ADB" อีกแล้ว: หลังจับคู่ทันที โทรศัพท์อาจยังไม่รู้จักคีย์ใหม่ชั่วครู่ จึงลองเชื่อมต่อซ้ำ
  • ล้างการแจ้งเตือน "กำลังจับคู่..." ที่ค้างอยู่

1.0.5

2026-10-21รุ่นที่ปล่อย

เพิ่มใหม่

  • การตั้งค่าขอสวิตช์ที่ซ่อนอยู่ของ ColorOS ก่อนจับคู่ ("ปิดการเพิ่มประสิทธิภาพระบบ" แสดงเฉพาะเมื่อโทรศัพท์ตั้งเป็นภาษาอังกฤษ)
  • การตั้งค่าอธิบายวิธีขยายการแจ้งเตือนรหัสจับคู่
  • ขั้นตอนสำหรับการแจ้งเตือน และปุ่ม "ทำแล้ว ไปต่อ" ในทุกการตรวจสอบอัตโนมัติ

แก้ไขแล้ว

  • ข้อความที่ชัดเจนแทน "Stream closed" เมื่อ ColorOS ปฏิเสธสิทธิ์
  • ตรวจพบ Wi-Fi แม้เปิด VPN อยู่

1.0.4

2026-10-20รุ่นที่ปล่อย

เพิ่มใหม่

  • ขั้นตอนที่เปิดการแจ้งเตือน (พิมพ์รหัสจับคู่ในการแจ้งเตือนหนึ่งรายการ)
  • ปุ่ม "ทำแล้ว ไปต่อ" ในทุกการตรวจสอบอัตโนมัติ สำหรับโทรศัพท์ที่รายงานผิด

แก้ไขแล้ว

  • ตรวจพบ Wi-Fi แม้เปิด VPN อยู่
  • พบตัวเลือกสำหรับนักพัฒนาแม้เปิดการแก้ไขข้อบกพร่อง USB อยู่
  • หน้าจอการตั้งค่าที่โทรศัพท์ไม่มีจะย้อนไปหน้าการตั้งค่าหลัก

  • แอปกลับมาด้านหน้าเองหลังจับคู่
