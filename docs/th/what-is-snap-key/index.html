Snap Key บนมือถือ OPPO คืออะไร?

Snap Key คือปุ่มจริงที่อยู่ด้านซ้ายตอนบนของมือถือ OPPO บางรุ่น เช่น ซีรีส์ Find X9 บน ColorOS ปุ่มนี้เรียกการทำงานหนึ่งอย่างจากรายการที่ตายตัวไม่กี่อย่าง เช่น AI Mind Space หรือไฟฉาย SnapKey Mapper แอปฟรี ทำให้ปุ่มเปิดแอปหรือลิงก์ไหนก็ได้แทน

ค่าเริ่มต้น

สิ่งที่ Snap Key ทำได้ตั้งแต่ออกจากกล่อง

บน ColorOS 16 ปุ่ม Snap Key ทำได้แค่สิ่งที่ OPPO กำหนดไว้: AI Mind Space กล้อง ไฟฉาย เครื่องบันทึกเสียง แปลภาษา จับภาพหน้าจอ โหมดเสียง หรือห้ามรบกวน คุณเลือกอย่างใดอย่างหนึ่งในการตั้งค่าโทรศัพท์ ไม่มีตัวเลือกให้เปิดแอปที่คุณต้องการ

นั่นคือช่องว่างที่ SnapKey Mapper เติมให้ แอปเก็บปุ่มไว้ และเพิ่มสิ่งที่การตั้งค่าไม่มีให้

FAQ

คำถามที่พบบ่อยเกี่ยวกับ Snap Key

ปุ่ม Snap Key คืออะไร

ปุ่มจริงที่อยู่ด้านซ้ายตอนบนของมือถือ OPPO บางรุ่น ในการตั้งค่า คุณเลือกการทำงานให้ปุ่มได้หนึ่งอย่างจากรายการที่ตายตัว แต่ถ้าใช้ SnapKey Mapper ปุ่มจะเปิดแอปหรือลิงก์ไหนก็ได้ และกดครั้งเดียว สองครั้ง สามครั้ง และกดค้าง เปิดคนละอย่างได้

Snap Key เหมือนกับ Plus Key ของ OnePlus ไหม?

เป็นปุ่มด้านข้างที่คล้ายกันบนมือถือของกลุ่มบริษัทเดียวกัน SnapKey Mapper ใช้ได้กับทั้งสองแบบ ดูหน้า Plus Key ของ OnePlus

AI Snap Key ของ Reno 16 คืออะไร?

เป็นชื่อที่ OPPO Reno 16, Reno 16 Pro และ Reno 16 F เรียกปุ่มด้านข้างของตัวเอง แอปใช้ได้กับปุ่มนี้ ถ้าเครื่องของคุณไม่ตอบสนอง บอกเราบน GitHub

Snap Key เปิดแอปไหนก็ได้ไหม?

ถ้าใช้แค่การตั้งค่าของ OPPO ไม่ได้ เพราะมีรายการการทำงานที่ตายตัว แต่ถ้าใช้ SnapKey Mapper ได้: แอปที่ติดตั้งไว้หรือลิงก์ไหนก็ได้

เกี่ยวข้องกับผลิตภัณฑ์อื่นที่ชื่อ Snap Key ไหม?

ไม่ ชื่อนี้ยังถูกใช้กับสิ่งที่ไม่เกี่ยวข้อง เช่น ฟีเจอร์ของแป้นพิมพ์และการตั้งค่าในเกม หน้านี้พูดถึงเฉพาะปุ่มด้านข้างของมือถือ OPPO
