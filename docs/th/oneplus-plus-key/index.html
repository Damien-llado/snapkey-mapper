ตั้งค่า Plus Key ของ OnePlus ให้เปิดแอปไหนก็ได้

Plus Key บนมือถือ OnePlus ให้เลือกการทำงานได้แค่ไม่กี่อย่างที่กำหนดไว้ เช่น Mind Space ไฟฉาย หรือโหมดเสียง SnapKey Mapper เป็นแอปฟรีและโอเพนซอร์สที่ให้คุณปรับแต่งปุ่มนี้ได้ จะเปิดแอปหรือลิงก์ไหนก็ได้ ด้วยการกดครั้งเดียว กดสองครั้ง กดสามครั้ง หรือกดค้าง

ตัวปุ่ม

สิ่งที่ OnePlus ให้ Plus Key ทำได้

ในมือถือ OnePlus หลายรุ่น Plus Key มาแทนที่แถบปรับการแจ้งเตือน ในการตั้งค่าโทรศัพท์ คุณเลือกการทำงานให้ปุ่มนี้ได้หนึ่งอย่าง เจ้าของเครื่องบน r/oneplus พูดถึงตัวเลือกที่ใช้กันอยู่ ได้แก่ Mind Space (AI ของ OnePlus) ไฟฉาย กล้อง จับภาพหน้าจอ เครื่องบันทึกเสียง แปลภาษา ห้ามรบกวน และสวิตช์เสียง สั่น ปิดเสียง รายการจริงขึ้นอยู่กับรุ่นและเวอร์ชันซอฟต์แวร์

สิ่งที่การตั้งค่าไม่มีให้ก็คือแอปที่คุณอยากเปิดจริงๆ เจ้าของเครื่องขอกันอยู่เรื่อยๆ ว่าอยากใช้ผู้ช่วยของตัวเอง แอปกล้องที่ตั้งเอง หรือการทำงานอื่นเมื่อกดสองครั้งหรือสามครั้ง

สิ่งที่แอปเพิ่มให้

Plus Key ปุ่มเดียว สี่ทางลัด

แต่ละรูปแบบการกดเปิดเป้าหมายของตัวเอง ตั้งหนึ่ง สอง สาม หรือทั้งสี่แบบก็ได้

  • สี่รูปแบบการกด

    กดครั้งเดียว กดสองครั้ง กดสามครั้ง และกดค้าง (ครึ่งวินาที) การกดต่อเนื่องจะรอเสี้ยววินาทีก็ต่อเมื่อตั้งการกดที่ต่อเนื่องนานกว่าไว้ เพื่อแยกให้ออก ถ้าไม่ได้ตั้งไว้ก็ทำงานทันที

  • แอปหรือลิงก์ไหนก็ได้

    เลือกแอปที่ติดตั้งไว้ วางลิงก์ หรือเขียนลิงก์ intent: สำหรับทุกอย่างที่ Android ทำได้ ปุ่มจะเปิดสิ่งนั้นให้ โดยไม่ต้องรูท

  • การทำงานในตัว

    เปิดหรือปิดไฟฉาย เปลี่ยนจากเสียงเป็นสั่นแล้วเป็นปิดเสียง เล่นหรือหยุดชั่วคราว แทร็กถัดไปและแทร็กก่อนหน้า ไม่มีอะไรเปิดขึ้น การทำงานเกิดขึ้นทันที โหมดปิดเสียงต้องมีสิทธิ์เข้าถึงห้ามรบกวน ซึ่งคุณอนุญาตครั้งเดียวก็พอ

  • เครื่องบันทึกเสียง

    ทางลัดเปิดเครื่องบันทึกเสียงของโทรศัพท์ พร้อมบันทึกโน้ตเสียง

  • คลังทางลัด

    ทางลัดสำเร็จรูปจัดกลุ่มตามแอป มีช่องกรอกแต่ละค่าและปุ่มทดสอบ ดูคลังทางลัด

วิธีตั้งค่า

ตั้งค่าบน OnePlus

ฉบับย่อ ส่วนคู่มือฉบับเต็มมีทุกหน้าจอและวิธีแก้ของแต่ละข้อผิดพลาด

  1. ปลดปุ่มออกจากการทำงานเดิมของมัน

    ในการตั้งค่าโทรศัพท์ เปิดการตั้งค่า Plus Key ถ้ามีตัวเลือกไม่ทำอะไร ให้เลือกตัวเลือกนั้น เพื่อไม่ให้ปุ่มเปิด Mind Space หรือไฟฉายพร้อมกัน บนมือถือ OPPO ระบบยังบันทึกทุกครั้งที่กด SnapKey Mapper จึงทำงานต่อได้ ถ้า OnePlus ของคุณทำงานต่างออกไป บอกเราบน GitHub

  2. ติดตั้ง APK และอนุญาตสิทธิ์ที่จำกัด

    ดาวน์โหลด APK แล้วเปิด จากนั้นไปที่ การตั้งค่า › แอป › SnapKey Mapper แตะ ⋮ แล้วแตะ อนุญาตให้เข้าถึงสิทธิ์ที่จำกัด Android ขอสิ่งนี้กับทุกแอปที่ติดตั้งนอก Play Store

  3. ให้แอปให้สิทธิ์อ่านบันทึกกับตัวเอง

    แอปต้องการสิทธิ์เดียว คือ READ_LOGS ซึ่ง Android ให้คุณให้สิทธิ์ได้ครั้งเดียวโดยไม่ต้องรูท รุ่นเต็มทำให้ผ่านการแก้ไขข้อบกพร่องผ่าน Wi-Fi ของโทรศัพท์เอง: ต้องใช้ Wi-Fi ครั้งเดียวนี้ ไม่ต้องใช้คอมพิวเตอร์ หน้าจออาจต่างออกไปบน OxygenOS และบางเวอร์ชันต้องเปิดสวิตช์ที่ซ่อนอยู่ก่อน ขั้นตอนที่ 3 ของคู่มือฉบับเต็มอธิบายไว้

  4. เลือกสิ่งที่แต่ละรูปแบบการกดจะเปิด

    เลือกแอป ลิงก์ หรือการทำงานในตัวสำหรับกดครั้งเดียว สองครั้ง สามครั้ง และกดค้าง แล้วแตะ ทดสอบการเปิด จากนั้นแอปจะรอฟังเอง

FAQ

คำถามที่พบบ่อยเกี่ยวกับ Plus Key

ตั้งค่า Plus Key ของ OnePlus ให้เปิดแอปไหนก็ได้หรือเปล่า?

ถ้าใช้แค่การตั้งค่าของ OnePlus ไม่ได้ เพราะมีรายการการทำงานที่ตายตัว แต่ถ้าใช้ SnapKey Mapper ได้: แอปที่ติดตั้งไว้หรือลิงก์ไหนก็ได้ และเปิดคนละอย่างสำหรับกดครั้งเดียว กดสองครั้ง กดสามครั้ง และกดค้าง

Plus Key กดสองครั้งหรือสามครั้งได้ไหม?

ได้ กดครั้งเดียว สองครั้ง สามครั้ง และกดค้าง ต่างก็มีเป้าหมายของตัวเอง เป็นแอป ลิงก์ หรือการทำงานในตัว หากจะล้างรูปแบบการกด ให้เลือกในแอปแล้วแตะ ลบออก

ใช้ Plus Key แทนแถบปรับการแจ้งเตือนได้ไหม?

ได้ การทำงานในตัว เสียง สั่น ปิดเสียง จะเปลี่ยนไปโหมดถัดไปทุกครั้งที่กด โหมดปิดเสียงต้องมีสิทธิ์เข้าถึงห้ามรบกวน ซึ่ง Android ขอให้คุณอนุญาตครั้งเดียว ถ้าไม่มี การสั่นจะกลับไปเป็นเสียง ข้อต่างจากการตั้งค่าของโทรศัพท์เองคือคุณเลือกรูปแบบการกดได้ และเก็บรูปแบบอื่นไว้ทำอย่างอื่น

ใส่ไฟฉายไว้ที่ Plus Key ได้ไหม?

ได้ การทำงานในตัว เปิดหรือปิดไฟฉาย จะเปิดไฟฉาย หรือปิดถ้าเปิดอยู่ ไม่มีแอปเปิดขึ้น

จับภาพหน้าจอ สลับห้ามรบกวน หรือเริ่ม Circle to Search ได้ไหม?

ไม่ได้ในฐานะการทำงานในตัว การทำงานในตัวมีแค่ไฟฉาย เสียง สั่น ปิดเสียง เล่นหรือหยุดชั่วคราว แทร็กถัดไป และแทร็กก่อนหน้า อะไรที่เปิดจากแอปหรือลิงก์ได้ก็ใช้ได้เช่นกัน แต่การจับภาพหน้าจอหรือสวิตช์ห้ามรบกวนทำไม่ได้

ต้องรูท Shizuku หรือ Tasker ไหม?

ไม่ต้อง แอปต้องการสิทธิ์เดียว คือ READ_LOGS ซึ่งแอปให้สิทธิ์ตัวเองครั้งเดียวผ่านการแก้ไขข้อบกพร่องผ่าน Wi-Fi ของโทรศัพท์ ไม่ต้องรูท ไม่ต้องใช้ Shizuku ไม่ต้องใช้ Tasker และไม่ใช้การช่วยเหลือพิเศษ FAQ หลักอธิบายว่าแอปเห็นอะไรได้และเห็นอะไรไม่ได้

OnePlus รุ่นไหนมี Plus Key บ้าง?

แอปใช้ได้กับ Plus Key ของ OnePlus 15, 15R, 13s, 13T และ Nord 5 โดย 13s และ 13T มีปุ่มนี้ ถ้าเครื่องของคุณมี Plus Key แต่ไม่อยู่ในรายการ ลองใช้แล้วบอกเราบน GitHub

ใช้ไม่ได้บน OnePlus ของฉัน ต้องทำอย่างไร?

เปิด ใช้กับโทรศัพท์ของฉันไม่ได้? ในแอป: แอปจะเริ่มรอฟังใหม่ คืนรูปแบบปุ่มเดิมถ้าถูกเปลี่ยนไว้ และเตรียม issue บน GitHub พร้อมรุ่น ระบบ และเวอร์ชันของคุณ คุณยังส่งบรรทัดบันทึกของปุ่มมาให้เราได้จากตัวค้นหาปุ่มของแอป
