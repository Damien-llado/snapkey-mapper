With Claude Code

If it can be launched, Claude Code can wire it to the key

Most apps open from a link, but nobody knows those links by heart. Ask Claude Code what you want the Snap Key to do. It finds the deep link, tests it on your phone over ADB, and gives you the line to paste in SnapKey Mapper.

  • Finds the right link for the app and the screen you want
  • Tests it before you touch the phone settings
  • Writes the webhook or shortcut behind it when there is no link yet

The use case that started it: the author runs Claude Code on a home server and talks to it from the phone through Remote Control. OPPO's settings could not open that conversation, Key Mapper only could while Wi-Fi was on. So this app was written, and it has been in daily use since October 2026.

Why

Why the Snap Key needed a mapper

On ColorOS 16, the Snap Key (the customizable button on the upper left side of the Find X9 and Find X9 Pro) can only do what OPPO lists: AI Mind Space, camera, flashlight, recorder, translate, screenshot, sound mode or do not disturb. There is no "open an app" option, and button remapping apps cannot see the key unless a debugging connection stays on.

SnapKey Mapper removes that limit. It does not change the button or patch the system: it works around the OS by watching what ColorOS already records.

Under the hood

How it works, honestly

  • ColorOS logs every press

    The system log gets a line with KEYCODE_ACTION_BUTTON_CLICK. SnapKey Mapper reads the log, spots that line and opens your app or link.

  • No root, no accessibility

    Reading the log needs one permission, READ_LOGS, granted once with a single command. It stays after a reboot.

  • Nothing leaves your phone

    No internet permission, so the app cannot send anything anywhere. It keeps only your target, the key name and the gesture.

Setup

Set it up in 6 steps

About 10 minutes, once. You need Wi-Fi only for step 2.

  1. Install the APK and allow restricted settings

    Download the APK and open it. Android blocks some sensitive settings for apps installed outside the Play Store: go to Settings › Apps › SnapKey Mapper, tap ⋮ then Allow restricted settings.

  2. Grant the log permission, once

    This is the only technical step. On ColorOS, first open Settings › Additional settings › Developer options and turn on Disable system optimisation (on ColorOS 16 it may only show when the phone is in English: switch the language for a minute if you cannot find it). Then run this command with ADB rights:

    pm grant io.github.damienllado.snapkeymapper android.permission.READ_LOGS

    Without a computer: install Key Mapper, start its Expert mode (wireless debugging, Wi-Fi needed), create a Shell command action, paste the command, choose ADB and tap Test. Exit code 0 means done; you can uninstall Key Mapper. With a computer: adb shell pm grant …. You can turn Disable system optimisation back off afterwards: the permission stays.

  3. Allow display over other apps and battery

    In SnapKey Mapper, tap Allow display over other apps (this is what lets Android open your app from the background) and Battery: do not restrict. On ColorOS, also set the app battery usage to No restrictions and lock SnapKey Mapper in the recent apps.

  4. Choose what the Snap Key opens

    Pick an installed app, or paste a link. Then choose single press, double press or long press, and tap Test to check it opens.

  5. Start listening

    Tap Start listening. Android 13 and newer asks "Allow access to all device logs?": choose Allow one-time access. That access lasts as long as the listening runs, so you only see it again after a reboot (tap the "SnapKey Mapper is off" notification).

  6. Optional: silence OPPO's own action

    In Settings › Snap Key, set the key to do nothing. ColorOS still logs every press, so SnapKey Mapper keeps working, and the key no longer triggers AI Mind Space or the flashlight at the same time.

Security tip. When you are done, turn off wireless debugging in Developer options. SnapKey Mapper does not need it.

FAQ

Questions

Can the Snap Key open any app on the Find X9 Pro?

Not with OPPO's settings alone: ColorOS offers a fixed list of actions. With SnapKey Mapper, yes: any installed app or any link, on single, double or long press.

Do I need root?

No. The app needs one permission, READ_LOGS, which Android lets you grant with an ADB command, without root and without unlocking the bootloader.

Do I need a computer?

No. Key Mapper can run the command from the phone itself through wireless debugging. A computer with adb works too.

Does it need Wi-Fi all the time?

No. Wi-Fi is only needed once, for the wireless debugging used to grant the permission. SnapKey Mapper keeps working on mobile data and with Wi-Fi off.

Why is "Disable system optimisation" needed?

Without it, ColorOS refuses the pm grant command ("Neither user 2000 nor current process has GRANT_RUNTIME_PERMISSIONS"). Turn it on, grant the permission, then turn it off again if you like.

Is it safe? What can the app see?

READ_LOGS lets an app read the system log, which can contain details from other apps. That is why SnapKey Mapper has no internet permission: it cannot send anything. It stores only your target, the key name and the gesture. The code is short and public: read it on GitHub, and only install builds from the official releases.

Why does Android ask for log access again?

Since Android 13, every new log reading session needs your consent, and only while the app is on screen. SnapKey Mapper keeps one session open, so you only answer again after a reboot or if the system stops the app.

The Snap Key stopped working after a reboot

Tap the "SnapKey Mapper is off" notification, then "Allow one-time access". Also check that battery usage is set to No restrictions and that the app is locked in the recent apps.

How do I find the name of my key on another phone?

Open SnapKey Mapper, tap Start capture, press your key two or three times, stop, then save the capture. Look for a line that appears once per press, with a KEYCODE_… name. On the Find X9 Pro it is KEYCODE_ACTION_BUTTON_CLICK (scan code 735).

What about the Quick Button on the right?

The Snap Key is on the upper left side. The Quick Button of the Find X9 Pro, on the right edge, is a camera control and has not been tested with SnapKey Mapper.

Does it drain the battery?

It waits for new log lines and does nothing in between. No drain was noticed in daily use on the Find X9 Pro, but this is an observation, not a benchmark.

Can it open a Claude Code, ChatGPT or WhatsApp conversation directly?

Yes, if the app accepts a link to that conversation. Paste the link as the target: Android opens it in the matching app when that app supports it, otherwise in the browser.

How do I find the link for an app?

Many apps document their links (Google Maps, Spotify, Home Assistant). Otherwise ask Claude Code or another assistant, then test the link with adb shell am start -a android.intent.action.VIEW -d "<link>" or with the Test button in SnapKey Mapper.

Will it be on Google Play?

No: install the APK from the GitHub releases. Google is also rolling out developer verification for apps installed outside the Play Store (2026 in some countries, worldwide in 2027); this page will explain any change for SnapKey Mapper.

How do I uninstall it?

Like any app. The permission goes away with it. Turn wireless debugging off if you left it on.

Is it affiliated with OPPO?

No. SnapKey Mapper is an independent open source project, not affiliated with OPPO, OnePlus, Key Mapper, Anthropic or any app shown on this page. These names only describe compatibility.
